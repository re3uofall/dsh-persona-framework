# impl/ —— 框架自身的程序

这里是「总模块」的实现层。目录里 37 个 `.mjs` 都是框架自己的程序：注入、调度、配额、自检、程序（program）的手脚全在这儿。

## 为什么单独一层

原来是 `lib/`，跟「库」这个说法混在一起——它其实不是给别的插件用的库，是**总模块自己的实现**。名字换成 `impl/`，是为了让三层分得开：

| 层 | 是什么 | 在哪 |
| --- | --- | --- |
| 总模块 | 骨架：注入时机、调度顺序、工具注册 | `index.js` |
| 程序功能实现 | 框架自己的实现程序 | `impl/*.mjs` |
| 模块正文 | 每轮按配额进上下文的那几篇 | `persona-ai/modules/*.md` |

## 规矩

- `index.js` 只做「接起来」：导入、注册、调用。实现写进 `impl/`。
- 改程序用 `framework_code`（`op=save` 会先留旧稿，写完当场 `node --check`）。
- 改完要重启 DSH 才生效——程序是启动时读进去的，重载插件不管用。
- 新增一个文件也算「改程序」：记得同时改 `index.js` 的导入，并跑 `node selfcheck.mjs`。
