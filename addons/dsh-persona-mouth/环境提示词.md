# 嘴 · 注入的那两处

这个插件只往上下文里放两样东西，都很短。

## 一、工具（谁都能看见）

- `mouth_say({to, text, channel})` —— 真送。送完先写嘴账，再回话。
- `mouth_receipt({limit})` —— 看嘴账。
- `mouth_pending()` —— 有没有送完还没说出口的。
- `mouth_channel()` —— 有哪几条道、各自通不通。

## 二、实时环境那一段（`实时环境:mouth`，order 42）

只在「有送完还没说出口的话」时出现，形如：

```
嘴：这一步之前真送出去 1 句（说的时候报送给谁、走的哪条道、收到没有，别报打算）——
- ✓ → 师父：「在」（file:file）
```

出现一次就算说过：触发器在注入之前已经把 `pending` 清空、`spokenAt` 写进
`.persona-framework/嘴账状态.json`。所以下一轮同一句不会再出现——
**不重复、不是提醒，是账上真多了一行。**

## 三、和手的区别（一句话）

手记账上的「动作」，嘴记账上的「话」。两边都只有一条判据：**盘上多一行，才准说出口。**
