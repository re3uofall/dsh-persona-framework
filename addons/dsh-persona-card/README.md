# dsh-persona-card · 人格卡片

两半：**语言与逻辑**、**结构与拓扑**。

## 一、语言与逻辑

每一句里能指的东西，都落成一张有位置的卡：

| 种类 | 是什么 | 判据 |
| --- | --- | --- |
| 指称 ref | 谁／什么 | 能指回原文哪一段 |
| 谓词 pred | 对它说了什么 | 和指称之间有一条「谓述」边 |
| 连接 conn | 两句之间怎么连 | 必须有确定的真值规则 |
| 量词 quant | 管多大一片 | 所有／有些／至少几 |
| 模态 modal | 必须还是可能 | 说清是义务还是可能 |
| 否定 neg | 翻真值 | 作用范围写清楚 |

连接词就是形式逻辑那六个：

- `∧` 合取：两句都真才真
- `∨` 析取：有一句真就真
- `¬` 否定：把真值翻过来
- `→` 蕴含：前真后假才假
- `↔` 等值：两句同真同假
- `∴` 推出：前提真时结论必须真

连不上的（连接词只有一边）不猜，记「未定」，并写出为什么。

## 二、结构与拓扑

把卡当图看：点、边、连通分量、环、悬挂点。**先说什么没变，才允许说什么变了。**

- 不变量：连通几段、环数（`边 - 点 + 连通`）、悬挂点、断裂点（拿掉它图就断）
- 变化：加了什么、减了什么、哪张卡换了邻居（**滑动**）
- 漂移度：`(加+减+滑) / (加+减+滑+8)`，0 到 1 之间，只作提示不作判据

参考后结构主义的一句：意义不在单个词里，在它和别的词的差异与位置里——位置一移，意思就滑。

## 工具

- `card_language`：`action=build` 拆一句（`text`、`source`）、`show` 看上次、`list` 看种类与连接词表
- `card_topo`：`action=topo` 看上次那张图、`compare text=…` 和新的一句比变化

## 段

`实时环境:card`，order **45**；拆过的卡少于 `showAfterCards`（默认 3）时不占前缀。

## 它不是什么

- 不是语法分析器：切分很粗，只认标点与连接词
- 不判真假：真值规则写在卡上，真不真要你自己对现实
- 不替代记忆：这本账只记「这句话怎么连起来的」
