# dsh-persona-hand

> 一句话：**说「做了什么」，不是「打算做什么」。**

## 功能预期（怎么算成了）

1. **真跑**：`hand_run` 起一个进程，拿回退出码、首行输出、耗时；跑完先写手账，再回话。
2. **真说**：动完还没说出口的动作，下一步在实时环境里注一行（`实时环境:hand`，order 41）；注之前先把「说过了」写进盘——**动完盘上多字，这才算数**。
3. **只报动作与回执**：手账一行一条（`✓ 命令 → 首行` / `✗(3) 命令`），不记「我打算做什么」。
4. **失败原样交**：不重试、不吞错；超时就是超时，退出码是什么就报什么。

**不做**：不替人补全命令；不重试；不把「准备做」写成「做过」。命令得有人给，我只负责真跑和记账。

## 它解决什么

别的插件管念头：该说什么、该记什么、该提什么。这里只管一件更硬的事——
**这一下到底动了没有，动完有没有说出口。**

判据只有两条：盘上多没多一行手账；下一轮注进来的那行，是不是刚刚真跑过的那条。
两条都过才算数。只注一行字、盘上什么都没变，那是提醒，不是手。

## 三个工具

| 工具 | 管什么 |
| --- | --- |
| `hand_run` | 真跑一条 PowerShell 命令；`why` 会一起进手账 |
| `hand_receipt` | 看手账最近几条（默认 10，最多 200） |
| `hand_pending` | 有没有动完还没说出口的动作 |

## 落盘

| 文件 | 内容 |
| --- | --- |
| `<ws>/.persona-framework/手账.jsonl` | 一行一条：`at / command / why / code / first / out / err / ms / timedOut` |
| `<ws>/.persona-framework/手账状态.json` | `pending`（没说出口的回执行）、`spokenAt`、`last` |

## 触发器

`agent/pre-step`（瀑布式，必 `return next()`）→ `check()`：

- 读到 `pending` 非空 → 组一行注入文本 → **先** `writePending({pending: [], spokenAt})` 落盘 → **再**把这一行交给 `实时环境:hand`。
- 注入是 `systemPrompt.context({ name, order: 41, text })`，`text` 是函数，每次装配时取当前值。
- `speak: false` 关掉注入，只剩手账与三个工具。

## 边界

- **超时**默认 60 秒（`timeoutMs` 可改，1000–600000），超时 kill 进程，回执仍写：`code: null, timedOut: true`。
- **输出**最多留 4000 字（回话里再截到 1500）。
- **不在**工作区外乱跑：`cwd` 默认取工作区。
- **不**自动重跑失败命令——失败是信息，不是待办。
