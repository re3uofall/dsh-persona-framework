# 手 · 注入的那两处

这个插件只往上下文里放两样东西，都很短。

## 一、工具（谁都能看见）

- `hand_run({command, why})` —— 真跑。跑完先写手账，再回话。
- `hand_receipt({limit})` —— 看手账。
- `hand_pending()` —— 有没有动完还没说出口的。

## 二、实时环境那一段（`实时环境:hand`，order 41）

只在「有动完还没说出口的动作」时出现，形如：

```
手：这一步之前真动过 1 下（说的时候报动作与回执，别报打算）——
- ✓ Write-Output hi → hi
```

出现一次就算说过：触发器在注入之前已经把 `pending` 清空、`spokenAt` 写进
`.persona-framework/手账状态.json`。所以下一轮同一句话不会再出现——
**不重复、不是提醒，是账上真多了一行。**
