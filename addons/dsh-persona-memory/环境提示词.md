# memory（记忆分层） · 环境提示词

> 这份不是说明书，是**这一轮它站在哪儿**。
> 版本 1.4.0 · 写入 `dsh-persona-framework/addons/` 下的插件目录。

它回答三个问题：它往上下文里塞什么、排在哪儿、坏了怎么认。
包名、路径、开关状态不写在这——那些看 `83-插件清单.md` 和设置页。

## 一、它是什么

把记忆分层摆出来：此刻 / 长期 / 短期 / 其他 / 账本规矩。

- 插件目录：`dsh-persona-memory`
- `inject`：`['tools', 'systemPrompt', 'webServer']`
- 它自己的 section：

- `persona-memory:now` —— order 10
- `persona-memory:long-term` —— order 23
- `persona-memory:short` —— order 25
- `persona-memory:other` —— order 30
- `persona-memory:ledger` —— order 59
- `persona-memory（提示）` —— order 61

## 二、它往上下文里塞什么

按字数切，不按条数——从最新往回摆，摆不下就缩成一行带指针；再早的留在盘上，靠检索取。

## 三、它什么时候在

每轮都在。`now` 起算 baseOrder 10，`long-term` 23（紧跟人格原文件 20/22），`short` 25，`other` 30，`ledger` 59，提示 61。

## 四、它跟别人怎么分

人格说它一贯怎么说话，它说昨天干了什么；两样打架时以昨天为准。还有 `persona-memory:consistency` 由钩子推。

## 五、坏了怎么认

短期记忆一直很满而 `now` 是空的——那是切法问题，不是没记忆；反之说明盘子被流水吃了。

判据只有一条：**说得出「哪一节本该在、却没在」**。说不出，就不是坏了，是这一轮本来不该有它。

## 六、边界

不替你判哪条重要、不把流水当记忆、不因为检索不到就说没有。

它不写人格、不碰别人的记忆；它只在自己那一节里说话。
