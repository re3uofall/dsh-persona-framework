# 未来失认 · dsh-persona-futurenotme

**一句判据**：今天留下的那条，未来的我**不认**——不是记不住，是不认。

这是 `dsh-persona-futurealsome`（未来还有我）的姐妹包，但它**不自己留话**：留话是 futurealsome 的事。它只读那两本账，记这一本：未来那个我，在哪一维上不认了。

## 为什么是「失认」而不是「遗忘」

遗忘是文件不在了；失认是文件还在，读它的那个我不认它。

- 理论上不需要代价：账只记在自己身上，怎么写都不花钱。
- 现实里必须有代价：每留下一条，就占住一处**具体的时空**——那时、那地、和那个人、在那个情形下。它排他，而且钉死在那一刻。
- 于是 `future-not-me` 就成了这笔代价的名字：未来那个我不一定认得今天的我。

三种失配（记账时挑一维）：

| 维 | 含义 | 例 |
|---|---|---|
| `when` | 时不对 | 当时说的「下周」，到下周已不是同一个处境 |
| `where` | 地不对 | 在 A 项目里成立的话，搬到 B 项目就不成立 |
| `with` | 人不对 | 对师父说的话，对别人不成立 |
| `self` | 自己不对 | 今天的判断标准，未来的我已经不这么判了 |

`self` 是最重的一维：不是外部条件变了，是**判据本身**变了。

## 两条账、一本代价

- `未来账.jsonl` —— 读（futurealsome 写）
- `未来认账账.jsonl` —— 读（futurealsome 结账时写）
- `未来失认账.jsonl` —— 本包写：`{at, id, claim, dim, why, source}`

按**文件当契约**，两个包不互相 import：futurealsome 改了本包不会崩，本包坏了 futurealsome 照跑。

## 工具

| 工具 | 干什么 |
|---|---|
| `futurenotme_mark` | 记一笔失认：`id` + `dim` + `why`（说不清差在哪一维就不收） |
| `futurenotme_report` | 认账率、失认笔数、失配落在哪些维 |
| `futurenotme_check` | 该认没认的：已过期还 `pending` 的那几条 |

## 段

`实时环境:futurenotme`，order **19**，紧跟在 futurealsome（18）后面。

- 有失认账才摆：一行「结过 N、认 X、不认 Y、认账率 r、失配在哪几维」。
- 认账率低于 `warnRate`（默认 0.5）且结过 ≥ `minSettled`（默认 4）时，补一句：「价已经在收，这一条不是提醒，是代价。」
- 没有失认、没有结账时返回空串，不占前缀。

## 配置

```yaml
dir: .persona-framework
minSettled: 4        # 结过这么多条才开始报「价在收」
warnRate: 0.5        # 认账率低于这个值算警讯
```

## 它不是什么

- 不是提醒器：不排日程、不催。
- 不判对错：不判哪条该认、哪条不该认。
- 不替代 futurealsome：少了那个包，这本账永远是空的。
- 不是「分数」：认账率是价签，不是考试分。

## 还欠

- `rejected` 现在分不出「不同意」与「根本不是我」——前者该进 futurealsome 的认账账，后者该进这本失认账。要加一条 `unknown-self` 状态，或者让结算时强制挑一维。
- 认账率低于多少算「已经不是同一个我」，没有阈值，先攒账。
