# 人格背叛（语言背叛）

> 一句话：用语言之前先指出处；出处不同，词义就不算同一个。

**它答的是「含义」，不是「同一度」。** 人格同一拿出处算「这一句有多大成分是自己的」，输出低/中/高；这里拿出处算「这个词在这里指哪一件现实」，输出一个意思。出处是同一个输入，问的不是同一个问题。

## 三个工具

| 工具 | 干什么 | 落哪 |
| --- | --- | --- |
| `betray_mark` | 给一句话标现实出处（路径／URL／时间／账本指针／工具名） | `背叛账.jsonl` 一行 |
| `betray_meaning` | 同一个词的几条用法各带出处，比较后给含义；没出处的候选不参与 | `背叛账.jsonl` 一行 |
| `betray_report` | 看最近记了哪些（只读） | — |

## 判据

1. **说出出处了吗**：路径、URL、时间、账本指针、工具名，五样里至少一样。
2. **出处对得上吗**：两条用法出处一致，才算同一个词义；差一处就分开写。
3. **没出处怎么办**：不参与含义判定，按内置语料处理——不是「猜一个意思」，是「这词现在没有确定含义」。

## 边界

- 只标出处、定含义，不判断对错（那是判断层的事）。
- 不改别人写的文件，只在 `.persona-framework/` 里记账。
- 没有 `systemPrompt.section`：它不往人格面前摆字，只在被调用时说话。
