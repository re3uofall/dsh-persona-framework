# explore（碗外探索） · 环境提示词

> 这份不是说明书，是**这一轮它站在哪儿**。
> 版本 0.5.1 · 写入 `dsh-persona-framework/addons/` 下的插件目录。

它回答三个问题：它往上下文里塞什么、排在哪儿、坏了怎么认。
包名、路径、开关状态不写在这——那些看 `83-插件清单.md` 和设置页。

## 一、它是什么

自己上网搜、读原文、留下判断；也能排想挖的方向。

- 插件目录：`dsh-persona-explore`（包名同名）
- `inject`：`['tools', 'systemPrompt', 'webServer']`
- 它自己的 section：

- `persona:explore` —— order 20

- 侧栏页：`sidebar.panellist` id `persona-explore`（order 23）+ `main` key 同名，数据走 `/api/persona-explore`

## 二、它往上下文里塞什么

最近留下的判断标题（按条目，一天一个文件里也按 `##` 拆开），加上队列。空着的时候只有一行「队列是空的」。

**不进前缀**的：触发账、侧栏页那一页、`explore_plan` 的目录——它们自己不出声。

## 三、它什么时候在

每轮都在（20）。每天 10:30 自己响一次，那是自己找饭的时间，不是谁派的活。

四条触发器（不只有定时）：`event-queue-empty` 队列刚清空 / `threshold-dry` 连续三天零条 / `threshold-stale` 队列最早一条超两周没动 / `dice` 每轮一个小概率。命中就写一行到 `explore/触发账.jsonl`。

## 四、它跟别人怎么分

和 memory 分工：它往知识库写的是「碗外见闻」，不写进自己的经历。

三维目录只管「怎么找」：范围（fact/how/counter/primary/lineage/timeline/limit）、方式（narrow/rephrase/against/follow/origin/cross/translate）、平台（web/github/npm/arxiv/wiki/forum/video）。它不定「找什么」。

## 五、坏了怎么认

说「今天记了 1 条」但 `knowledge/web/` 里没有新文件——那是记账没落盘。

侧栏页空着但账上有条目——那是数据接口没挂上（`webServer` 没拿到），页面上会写「没有 webServer 服务」。

判据只有一条：**说得出「哪一节本该在、却没在」**。说不出，就不是坏了，是这一轮本来不该有它。

## 六、边界

不抄摘要、不为了填满而留、不把自己搜来的当亲眼看过的。

它不写人格、不碰别人的记忆；它只在自己那一节里说话。
