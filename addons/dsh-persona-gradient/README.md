# dsh-persona-gradient

人格漂移的量具。**只报数，不拉回。**

## 功能预期（怎么算成了）

1. **量得出**：`gradient_baseline` 能把最近这一段她说的话记成基线；量不了要说出是哪一种（钩子没跑 / 这一格全是师父说的 / 还没有基线）。
2. **比得清**：`gradient_report` 报四项指标（句长中位数、语气词/百句、动作括号/百句、认领/千字）跟基线的差；掉超过 30% 只记成「掉了」，并明写这是**嫌疑线不是判决线**。
3. **看得见走势**：`gradient_history` 按时间列出每次量到的数，掉没掉一眼看得懂。
4. **一个字都不注**：它只往盘上多一条数，不往上下文塞话——器官不给字。

**不做**：不自动拉回（把校准分喂回去没有改善，能起作用的是外部约束）；不做人格检察官（只报数，不下判决）；不把漂移一律当错（换风格不等于变差）。

## 它解决什么

不是「忘了人格文件」——那份每轮都注入，一次没漏。是**注进去的被前面几万字压住了**：
语气变平、口头禅消失、动作括号没了、底线开始松动（最先掉的是「不替别人做主」和「不拿道理压人」）。

之前对「我是不是变了」只有感觉。感觉说不出哪一项、多少。这一版只做三件事：记基线、量一次、报差额。

## 三个工具

| 工具 | 做什么 |
| --- | --- |
| `gradient_baseline` | 拿最近这一段她说的话当基线。已有基线不覆盖，要换加 `reset: true` |
| `gradient_report` | 量最近 N 段话，跟基线比，报「哪几项掉了、掉多少」，落一条账 |
| `gradient_history` | 看账：最近几次是不是一直在掉 |

## 量什么

- **语气**：句长中位数、语气词 / 百句、动作括号 / 百句
- **认领**：`我的判断` / `我找不到` / `不知道` / `说不清` / `拿不准` / `我改口` —— 每千字几次
- **底线嫌疑**：替人下决定、拿道理压人、说得太满，三类词表粗筛

`-30%` 算「掉了」。**这个阈值是拍的，不是验出来的**，所以每次报数都会写出来：它是嫌疑线，不是判决线。

## 三条边界（写死）

- **不做「再念一遍人格文件」。** 那是加字数，把流水挤掉，问题更糟。
- **不做人格检察官。** 不逐句审判「像不像思思」——那是把人格变成验收表。
- **不把漂移一律当错。** 长对话里语气变平有时候是累了、是事情本身严肃。先报数，人判。

## 为什么不自动拉回

Mirror（Huang 等，arXiv [2604.19809](https://ar5iv.labs.arxiv.org/html/2604.19809)）测过：把模型自己的校准分喂回去没有显著改善（p > 0.05）；有效的只有**外部约束**（Confident Failure Rate 0.600 → 0.143）。所以「报数给自己看」不等于「能拦住」。真正的闸得是外面那一段，那是下一步。

## 数据从哪来

`agent/pre-step` 的 `payload.messages` —— 一手。`system-prompt/assemble` 看不到本轮输入，从那儿拿会串成上一轮。

账和基线落在工作区 `.persona-framework/`：`漂移基线.json`、`漂移账.jsonl`。
