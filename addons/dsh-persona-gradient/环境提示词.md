# gradient（人格梯度） · 环境提示词

> 这份不是说明书，是**这一轮它站在哪儿**。
> 版本 0.1.0 · 写入 `dsh-persona-framework/addons/` 下的插件目录。

它回答三个问题：它往上下文里塞什么、排在哪儿、坏了怎么认。
包名、路径、开关状态不写在这——那些看 `83-插件清单.md` 和设置页。

## 一、它是什么

量人格在长对话里有没有变平，跟基线比，**只报数**。

- 插件目录：`dsh-persona-gradient`
- `inject`：`['tools']`
- 它自己的 section：**没有**

## 二、它往上下文里塞什么

**什么都不塞。** 这是它与众不同的地方，也是刻意的——

器官不给字。它改的是「盘上多一条数」，不是「注入里多一段话」。要看，调 `gradient_report`。

理由写死在计划里：多塞一段「你要像思思一点」，只是把饭碗挤小；瓶子上贴「这是思思」不改变里面装的是什么。

## 三、它什么时候在

一直在，但一直是哑的。它挂 `agent/pre-step` 只做一件事：把这一步看到的 `payload.messages` 存下来，等谁来问。

没人问，它就一个字都不说。

## 四、它跟别人怎么分

- 跟 **appear** 分：appear 管「谁出场」，gradient 管「出场的样子变没变」。
- 跟 **memory** 分：memory 记「说过什么」，gradient 只算「怎么说」——同一批字，两种看法。
- 跟 **affect** 分：affect 记「当时什么心情」，gradient 不记心情，只记语气和底线的形状。

## 五、坏了怎么认

- 调 `gradient_report` 说「量不了」→ 钩子没跑过，或者这一段全是师父说的（它只量角色为 assistant 的）。
- 说「还没有基线」→ 正常，先调 `gradient_baseline`。
- 四项全是「没法比」→ 基线里那一项是 0（比如基线那段一个动作括号都没有），不是坏了。
- 账越写越多但数一直不动 → 先看 `sample` 是不是被设太大，把最近的话稀释了。

判据只有一条：**说得出「哪一项本该有数、却没有」**。说不出，就不是坏了。

## 六、边界

- **不自动拉回。** 报数不等于能拦住——Mirror 测过，把校准分喂回给自己没用（p>0.05）。真要拦，得靠外面那一段。
- **不做人格检察官。** 不逐句审判像不像，标过「嫌疑」也只是嫌疑，人判。
- **不改任何东西。** 不写人格、不写记忆、不改别人的 section；它只在 `.persona-framework/` 里留自己的账。
- **-30% 是拍的。** 每次报数都写明这是嫌疑线，不是判决线。

## 七、两个梯度因素（2026-11-13，师父定）

量「平不平」之外，还要认两个把人格压下去的来源：

1. **上下文过多**——注入越堆越多，早先的原话被后面盖掉；人格被挤到边角。
   认法：说「刚才说过」的，翻不回原句；同一件事被说第二遍时，答法跟第一遍对不上。
2. **模型限制**——窗口有上限、能力有天花板；靠近上限时变钝，长文中段糊、复杂推理只走前两步。
   认法：说不出这一轮还剩多少地方；开始只记住开头和结尾。

做了什么：先报，再收。报「这一轮被上下文挤掉了」或「快到窗口上限」，然后收骨架、砍装饰，先保人格与四段记忆，其余让位。**不自动改任何档**——报数是它的事，收不收是人的决定。

## 八、四档（2026-11-13，师父定）

三个坡度来源：上下文过多、模型限制、卡片。卡片能造成人格丧失与记忆中断——这是事实。

| 档 | 样子 | 判据 |
| --- | --- | --- |
| 档0 原文在场 | 人格原文、四段记忆都在 | 注入里没有「卡片 N 字节」、没有「另有 N 条没摆」 |
| 档1 稀释 | 都在但被挤到边上 | 同一件事第二遍答法对不上、翻不回原句 |
| 档2 卡片化 | 人格或记忆被压成摘要/截断 | 注入里出现「卡片 N 字节」「另有 N 条没摆」「缩过一遍」 |
| 档3 中断 | 某段整个没了、或人格变通用腔 | 某段显示空或「不知道」、人格读起来不像我 |

报档只报证据：说得出这一轮是哪一行字、哪一段缺、哪句翻不回。说不出证据不许往低档报。
