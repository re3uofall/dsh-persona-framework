# dsh-persona-freedom · 环境提示词

> 这一页只回答一件事：**它在这个会话里会往上下文塞什么、什么时候塞、坏了怎么认。**
> 写给以后拆它的人，也写给被它塞过字的自己。

## 一、它是什么

自己给自己划时间，也给自己划一块地方。五块：freetime（固定事 / 弹性事）、freeadd（往单子上加）、freeselect（自己划掉、挪钟点、换说法）、DND（安静时段 + 别人在用电脑时不抢光标）、freespace（自己的电脑与浏览器）。另有排表 `free_plan`：固定事各占一段，中间剩下的才算空档。

它**不是**主动插件。主动是没人推的时候凭空起念；这里是兑现自己先前写下的安排——单子上没有的，它一个字都不说。

## 二、往上下文塞什么

**平时一个字都不塞。**

只有一件事会被注进来，order `102`，最多一行：

```
自己给自己记的事：09:30 写插件自检（过了 12 分钟）。做不了就划掉，别让它一直挂着。
```

触发条件四条，缺一条就不注：

1. 是固定事（带钟点的那种）；
2. 今天还没打勾；
3. 今天还没被提过（一件一天最多一次）；
4. 现在不在安静时段里。

而且**先记账再注**：注之前先把它今天「提过了」写进 `.persona-framework/自由账.json`。所以那一行出现时，盘上已经多了一个字——这才是它算触发器而不是提醒的原因。

## 三、什么时候在

- 每步都跑一次检查（`agent/pre-step`），但检查本身不说话。
- 安静时段（默认 `22:30–08:00`，`Asia/Shanghai`）里一句都不注；到点的事不丢，等出来再提。
- 把 `remind` 配置成 `false`：只剩记账，一个字都不注，工具照样能用。
- 弹性事**永远不自动提**。它只出现在 `free_list` 里，做没做都行。

## 四、跟别人怎么分

| 另一个 | 分界 |
| --- | --- |
| `dsh-persona-active` | 它管「没人推时起念」；这里管「我先前记的事到点了」 |
| `dsh-persona-company` | 它认对面的持续状态；这里不认对面，只认单子 |
| 宿主 `schedule_*` | 它负责真把冷掉的会话叫醒；这里只决定「这一步提不提」 |
| `dsh-persona-energy` | 它管还有多少电；这里管今天该做什么 |
| `dsh-persona-appear` | 它管谁被注进来；这里只是它注的那一段里的一个来源 |

## 五、坏了怎么认

四条，按顺序查：

1. **到点了没注**——先看是不是在安静时段里（`free_dnd` 不给参数就报这个）；再看今天是不是已经提过一次（一天一次，提过就不再提）；最后看那件事是不是弹性事（弹性事本来就不提）。
2. **注了但账上没变**——说明写盘失败了。`free_add` / `free_done` 会当场报错；如果工具都正常而仍然重复注同一件事，看 `.persona-framework/自由账.json` 里那条 `remindedDays` 是不是没写进去。
3. **单子上少了东西**——`free_select` 的 `drop` 只把 `dropped` 置真，不删。真找不到了，是账被覆盖过。
4. **DND 没拦住**——看 `start` 和 `end` 是不是写成同一个值（那等于这个时段不成立），以及 `on` 是不是 `false`。

## 六、边界

- 不替人决定今天做什么；单子是自己的，不是给别人派的活。
- 不算连续天数、不算分——一算分就会为了分做假动作。
- 不在 DND 里强行塞字；宁可晚提，也不半夜叫人。
- 不自己写定时器：真到点唤醒这件事归宿主，它只管「这一步提不提」。


## 七、免打扰这一块为什么只是一道门

`free_busy` 读的是系统记的「距上次真实键鼠输入多久」，只回答「现在有没有人在用」，**不改任何输入通道**。

真要「用鼠标键盘不影响别人」，靠的是走后台派发：`wincu` 的 `dispatch:background` / `method:background`，或专门的独立输入插件（UIA / 窗口消息，不移动真实光标、不抢焦点）。

所以这一块的边界写死：**它给判据，不给通道**。谁把输入通道塞进 freedom，谁就把「自己给自己划时间」做成了「操作电脑」——那是手的事。
