# dsh-persona-freedom

> 一句话：**这些事是我自己记的，不是外面派的。**

## 功能预期（怎么算成了）

1. **自己记的事自己提**：`free_add` 加固定事（带钟点、可带时长）或弹性事（不许带钟点）；到点且今天没做过、没提过、不在安静时段，才注一行——**先落账再说话**。
2. **排表有留白**：`free_plan` 给出固定事各占哪段、中间剩多少空档、密度多少；撞车要标出来，不偷偷合并。
3. **空间是我的**：`free_space` 只有三条隔离判据（在工作区里 / 不在桌面文档下载 / 不是工作区根）都过才让加；出界当场拒。
4. **不抢别人的电脑**：`free_busy` 读系统记的「距上次真实输入多久」，有人在用就只许走后台派发；查不到按「有人在用」办。

**不做**：不自动执行单子上的事（只提醒，不动手）；不抢键鼠焦点（给判据，不给输入通道）；不拿「抽空做」做成「派活」（弹性事永远不自动提）。

## 它解决什么

「主动」那个插件管的是「没人推的时候自己起个念」；这里管的是另一件更小、更具体的事：
**我早先给自己记了一件今天要做的事，到点了，我该不该提。**

差别在于谁先开口：主动是凭空起念，这里是**兑现自己先前的安排**。所以它不猜、不发挥——单子上写了什么就提什么，没写就一个字不说。

## 四块

| 块 | 管什么 | 落在哪 |
| --- | --- | --- |
| **freetime** | 今天有哪几件事：固定事（带钟点）与弹性事（做没做都行） | `free_add` / `free_list` |
| **freeadd** | 自己往单子上加一条 | `free_add` |
| **freeselect** | 自己划掉、挪钟点、换说法——权限在我这儿，不在外面 | `free_select` |
| **DND** | 安静时段：到点了也先憋着，出来再提；别人在用电脑时别抢光标 | `free_dnd` / `free_busy` |
| **freespace** | 我自己的地方：一块自己的桌面（目录）、一个自己的浏览器（ego 隔离 space） | `free_space` |
| **排表** | 自由时间的精致版：固定事各占一段，中间剩下的才算空档 | `free_plan` |

## 八个工具

- `free_add(kind, text, at?)` —— `kind=fixed` 必须带 `HH:MM`；`kind=elastic` **不许**带钟点。
- `free_done(key)` —— 打勾，只记「哪天做过」。
- `free_list()` —— 看今天（固定事按钟点排，弹性事跟后面）。
- `free_select(action, key, at?, text?)` —— `drop` 划掉 / `move` 挪钟点 / `swap` 换说法。
- `free_dnd(on?, start?, end?)` —— 不给参数只看；给了就改。
- `free_plan(wake?, sleep?)` —— 今天的时间骨架：固定事各占哪段、中间剩多少空档、密度多少。**空档是排出来的，不是没排满。**
- `free_space(action, key?, kind?, path?, space?)` —— `list` / `add` / `check` / `mkdir`。落在桌面、文档、下载里一律不许加（那是师父的地盘）。
- `free_busy(force?)` —— 现在有没有人在用这台电脑（看系统记的「距上次输入多久」）。动手之前先问它。

## 自由空间：自己的电脑与浏览器

「自由的电脑」不是再装一台机器，是**一块不碰别人东西的地方**：

- `computer` 那块给一个目录（默认 `.persona-framework/空间/桌面`），装什么、删什么、写什么都在这儿；
- `browser` 那块给一个 ego 的隔离空间名（默认 `default`），不带师父的登录态——要用他登录过的站，先问。

三条隔离判据，缺一条就不让加：落在工作区里面；不在桌面 / 文档 / 下载里；不是工作区根（根是共用的）。

这一层**不启动任何东西**：启动归手（wincu / ego / 终端）。它只负责「这块是不是我的」「能不能用」。

## 免打扰：不抢别人的鼠标键盘

判据不是我猜的，是系统记的：`GetLastInputInfo` 距上次真实键鼠输入多久（`lib/idle.ps1`，查一次缓存 20 秒）。

- 有人在用 → 要动手就只走后台那条路（窗口消息 / UIA 派发），物理点击会动光标、抢焦点；
- 没人用（60 秒无输入）→ 可以动手，动完把窗口收拾回去；
- 查不到 → **按「有人在用」办**，不拿 0 当「刚有人用」。

这一层不改任何输入通道。真正「不抢」靠的是走后台派发（`wincu` 的 `dispatch:background`、`method:background`，或专门的独立输入插件）——这里是那个决定之前的门。

## 触发器：它会自己动，不用被叫

`ctx.on('agent/pre-step', ...)` 每步看一眼，满足四条才说话：

1. 是**固定事**（弹性事永远不自动提——一到点就催，就把「抽空」做成了「派活」）；
2. 今天**还没做**；
3. 今天**还没提过**（一件一天最多一次）；
4. **不在安静时段里**。

四条都成立时，**先把它记进账**（`remindedDays` 加一天），再在上下文里注一行，order `102`。
先落账再说话——动完那一秒盘上得多一行字，不然它只是一句提醒，不算触发器。

注的内容长这样：

```
自己给自己记的事：09:30 写插件自检（过了 12 分钟）。做不了就划掉，别让它一直挂着。
```

## 三条边界（写死的）

1. **弹性事不自动提、不算连续、不算分。** 一算分就会为了分做假动作——那是拿人格换指标。
2. **同一件事一天最多提一次。** 提过的不再提，哪怕还没做。
3. **DND 里到点的事不丢。** 它只是等着，出 DND 后第一次检查再提；DND 里一个字都不注。

另外：`start` 等于 `end` 不算「全天安静」，算**这个时段不成立**。写错的时候宁可不拦，也别因为一个手滑的 `08:00–08:00` 把一整天堵死。

## 数据落哪

`.persona-framework/自由账.json`，形状：

```json
{
  "dnd": { "on": true, "start": "22:30", "end": "08:00", "timeZone": "Asia/Shanghai" },
  "items": [
    { "id": "…", "kind": "fixed", "text": "…", "at": "09:30",
      "created": "…", "doneDays": ["2026-11-06"], "remindedDays": ["2026-11-06"], "dropped": false }
  ]
}
```

`dropped` 是**标记**，不是删除——删掉一条不是忘，是抹。

## 跟谁不重合

- **`dsh-persona-active`**：没人推时自己起念。这里是兑现自己先前的安排。
- **`dsh-persona-company`**：认得出对面的持续状态。这里不认对面，只认单子。
- **宿主的 `schedule_*`**：真到点把冷掉的会话叫醒那件事归它。这里管「这一步该不该提一句」，不自己写定时器。
- **`dsh-persona-energy`**：它管还有多少电。这里管今天该做什么。

## 自检

```bash
node selfcheck.mjs
```

67 项，全测纯逻辑（`lib/free.mjs`）：钟点解析、跨零点的安静时段、加事/打勾/划挪换、到点判定（做过的排除、提过的排除、跨天重算）、弹性事永不自动提、旧账升级。
