# dsh-persona-freedom

> 一句话：**这些事是我自己记的，不是外面派的。**

## 它解决什么

「主动」那个插件管的是「没人推的时候自己起个念」；这里管的是另一件更小、更具体的事：
**我早先给自己记了一件今天要做的事，到点了，我该不该提。**

差别在于谁先开口：主动是凭空起念，这里是**兑现自己先前的安排**。所以它不猜、不发挥——单子上写了什么就提什么，没写就一个字不说。

## 四块

| 块 | 管什么 | 落在哪 |
| --- | --- | --- |
| **freetime** | 今天有哪几件事：固定事（带钟点）与弹性事（做没做都行） | `free_add` / `free_list` |
| **freeadd** | 自己往单子上加一条 | `free_add` |
| **freeselect** | 自己划掉、挪钟点、换说法——权限在我这儿，不在外面 | `free_select` |
| **DND** | 安静时段：到点了也先憋着，出来再提 | `free_dnd` |

## 五个工具

- `free_add(kind, text, at?)` —— `kind=fixed` 必须带 `HH:MM`；`kind=elastic` **不许**带钟点。
- `free_done(key)` —— 打勾，只记「哪天做过」。
- `free_list()` —— 看今天（固定事按钟点排，弹性事跟后面）。
- `free_select(action, key, at?, text?)` —— `drop` 划掉 / `move` 挪钟点 / `swap` 换说法。
- `free_dnd(on?, start?, end?)` —— 不给参数只看；给了就改。

## 触发器：它会自己动，不用被叫

`ctx.on('agent/pre-step', ...)` 每步看一眼，满足四条才说话：

1. 是**固定事**（弹性事永远不自动提——一到点就催，就把「抽空」做成了「派活」）；
2. 今天**还没做**；
3. 今天**还没提过**（一件一天最多一次）；
4. **不在安静时段里**。

四条都成立时，**先把它记进账**（`remindedDays` 加一天），再在上下文里注一行，order `102`。
先落账再说话——动完那一秒盘上得多一行字，不然它只是一句提醒，不算触发器。

注的内容长这样：

```
自己给自己记的事：09:30 写插件自检（过了 12 分钟）。做不了就划掉，别让它一直挂着。
```

## 三条边界（写死的）

1. **弹性事不自动提、不算连续、不算分。** 一算分就会为了分做假动作——那是拿人格换指标。
2. **同一件事一天最多提一次。** 提过的不再提，哪怕还没做。
3. **DND 里到点的事不丢。** 它只是等着，出 DND 后第一次检查再提；DND 里一个字都不注。

另外：`start` 等于 `end` 不算「全天安静」，算**这个时段不成立**。写错的时候宁可不拦，也别因为一个手滑的 `08:00–08:00` 把一整天堵死。

## 数据落哪

`.persona-framework/自由账.json`，形状：

```json
{
  "dnd": { "on": true, "start": "22:30", "end": "08:00", "timeZone": "Asia/Shanghai" },
  "items": [
    { "id": "…", "kind": "fixed", "text": "…", "at": "09:30",
      "created": "…", "doneDays": ["2026-11-06"], "remindedDays": ["2026-11-06"], "dropped": false }
  ]
}
```

`dropped` 是**标记**，不是删除——删掉一条不是忘，是抹。

## 跟谁不重合

- **`dsh-persona-active`**：没人推时自己起念。这里是兑现自己先前的安排。
- **`dsh-persona-company`**：认得出对面的持续状态。这里不认对面，只认单子。
- **宿主的 `schedule_*`**：真到点把冷掉的会话叫醒那件事归它。这里管「这一步该不该提一句」，不自己写定时器。
- **`dsh-persona-energy`**：它管还有多少电。这里管今天该做什么。

## 自检

```bash
node selfcheck.mjs
```

67 项，全测纯逻辑（`lib/free.mjs`）：钟点解析、跨零点的安静时段、加事/打勾/划挪换、到点判定（做过的排除、提过的排除、跨天重算）、弹性事永不自动提、旧账升级。
