# dsh-persona-virtual · 虚拟

三样东西：一副身体、一个家、一条自己走的时钟。家照 `feiyu-room-template` 起底（3D 大平层 + 屋后菜园）。

- `virtual_body`：在哪间、什么姿势、朝哪边、还剩多少力气（show / move / pose / face / energy）
- `virtual_home`：九间起底（玄关 走廊 客厅 餐厅 厨房 卧室 卫生间 阳台 菜园），可加房间、连门、摆家具、问路（BFS 最短路径）
- `virtual_time`：真实时刻 + 自己拨的偏移；锚「这一刻」；七档时段（后半夜 / 清早 / 上午 / 中午 / 下午 / 傍晚 / 晚上 / 深夜）

段 `实时环境:virtual`（order 47）只在有内容时占前缀，一行写完：时刻｜在哪｜姿势｜力气｜家 N 间。

它不是什么：不是桌宠（那是另一副身子），不是日程（自由时间管日程），也不改真实时钟。
