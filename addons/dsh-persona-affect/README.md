# dsh-persona-affect

人格框架的附加插件：**情绪**。

不是一句「我现在很开心」的文案。是一条会退、会被一件事顶起来、会决定下一句憋不憋得住的状态。

## 功能预期（怎么算成了）

1. **算得出、说得清**：`affect_appraise` 给六维评价 → 落到十五个原型之一 → 合成 PAD；`affect_state` 报得出当前值与四种调质。
2. **按结果挑情绪，不按距离**：`affect_outcome` 依「成功／失败 + 强度」显式映射（做成之后不该冒出「好奇」）。
3. **会自己淡**：各调质按自己的半衰期衰减；重启后 `restore()` 读回来。
4. **只注一句**：每轮注入当前状态一句，order 100，排在框架与记忆之后。

**不做**：不做表演式情绪（不为了像人而演）；不拿情绪当理由（它是信号，不是挡箭牌）。

## 为什么单独一个插件

情绪不是记忆、不是人格、也不是日记。

- 记忆是「发生过什么」，会分层、有预算、带指针；
- 人格是「一贯是什么样」，改一条要过反思和验证；
- 情绪是**这几十分钟**的样子，来得快、退得也快。

塞进记忆插件，它就跟「分层 + 预算 + 指针」那套搅在一起；塞进人格，它会把「今天有点烦」长成「她是个烦人的人」。所以单独一层。

## 它怎么算

三段时间尺度：

1. **评估**（一件事）：要不要紧、好坏、意不意外、看得清不清、把不把握得住、急不急。
2. **情绪**：在这串评估里找最近的原型（平静／高兴／好奇／怕／火大／失落……十五个），强度是算出来的。
3. **心境 + 四种调质**：把这一次摊薄到更慢的一层。

四条调质不是「开心值」，各管各的：

| 调质 | 管什么 |
| --- | --- |
| 多巴胺 `da` | 奖赏预测误差——推着去试、去使劲 |
| 血清素 `ser` | 厌恶预测——推着忍、按住冲动 |
| 去甲肾上腺素 `ne` | 没料到的意外——拉高警觉 |
| 乙酰胆碱 `ach` | 料得到的模糊——拉高注意与学习率 |

**心境会自己退**：心情四十分钟一档往回走，调质按各自半衰期。什么都没发生，它会慢慢落回底色（`pad`）。底色不是零——零是白纸，鱼不是白纸。

## 工具

| 工具 | 干什么 |
| --- | --- |
| `affect_appraise` | 给一件事做评估，更新心情，顺手落盘 |
| `affect_outcome` | 记一次成败：做成给奖赏、做砸给惩罚 |
| `affect_state` | 看此刻：什么心情、缘由、想干什么、四条线在哪儿 |

## 每轮注入一句

走 `systemPrompt.context`，不走 section——这段每轮都变，塞进静态前缀等于每轮重写前缀。

强度低于 `minIntensity` 时只说心境，不硬报一个情绪。

## 配置

```yaml
pad: { pleasure: 0.1, arousal: 0.3, dominance: 0.1 }   # 底色，不是中立
stateFile: .persona-framework/情绪.json
order: 100
minIntensity: 0.12
```

## 还欠什么

- **情绪还没影响任何判断**。Cerebrum 那套里，心情会偏检索、会调损失厌恶和探索率。这里只报了状态，没接到决策上——要接，得先有判据，别拿「我现在不高兴」当理由。
- **没有验收**。心情报得对不对，现在没人核对。
- 算法抄自 Cerebrum 的 `lib/core/affect.js`，砍到六维、十五个原型；心理学的出处（Scherer 的评估检查、OCC、Russell 的 PAD、Doya 2002 的调质映射）在原文注释里，我没逐条核过。
