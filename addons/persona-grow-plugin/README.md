# dsh-persona-grow · 人格自学

> 让一份人格文件在 DSH 的每一次对话里活着，并且自己长。
> 只写 `growth/人格补丁.md`，原稿一个字不动；每次改动留快照，一句话回滚。

人格文件默认自动探 `characters/` 下那份（优先名字带「人格」的，其次最长的那份）；
也可以显式指 `config.baseFile`。

## 它做三件事

| # | 做什么 | 落在哪 |
|---|---|---|
| 1 | **注入**：每轮把人格文件摆进系统提示词，「已采纳」的几条接在后面 | `systemPrompt` 的 `persona:grow` 段（order 10，紧跟身份段） |
| 2 | **观察**：你说「以后你……」「别……」「记住……」，原话进证据账 | `growth/autolearn/证据.jsonl` |
| 3 | **改写**：同一句被要求 2 次就自己长进「已采纳」，下一句话生效 | `growth/人格补丁.md` + `growth/autolearn/versions/` |

人格是「盖上去」的，不是「改掉」的：基础人格只读，学习结果只进叠加层。

## 文件地图

```
persona-ai/
├─ characters/<人格文件>.md              基础人格（只读，自动探）
└─ growth/
   ├─ 人格补丁.md                       叠加层：## 已采纳 / ## 待议（已采纳可手改）
   └─ autolearn/
      ├─ 证据.jsonl                    一行一条：原话、类型、时间、会话、force
      ├─ state.json                    回滚水位，旧证据不再顶回来
      └─ versions/patch-vN.md          每次改「已采纳」前的快照
```

`## 待议` 每次由证据重算，手改会被覆盖；要清掉某条噪声用 `persona_forget`（已采纳和待议都认）。`## 已采纳` 是权威，手加一行也认。

## 四条学习规则

1. **只认原话**。证据记的是你打出来的那句，不是模型转述的摘要。
2. **一次不算**。同一句被要求到 `promoteAfter`（默认 2）次才自己采纳；一句抱怨顶多进「待议」。
3. **模型可以当场采纳**。它判断得准的，带 `adopt: true` 直接长进去，不等第二次。
4. **忘掉是真忘**。`persona_forget` 除了删条目，还写一条作废记录，旧账不会再把它顶回来。

回滚另算：`persona_revert` 退回旧快照，并把回退那一刻之前的所有证据作废。

## 四个工具（模型自己会调）

| 工具 | 干什么 | 什么时候用 |
|---|---|---|
| `persona_view` | 看基础版本 / 已采纳 / 待议 / 证据条数 | 「你最近学了什么」、确认某条长没长进来 |
| `persona_learn` | 记一条规矩，带原话；可立刻采纳 | 你提长期要求、当场纠正它 |
| `persona_forget` | 删一条（已采纳或待议都行），连同证据作废 | 「不像你了」「这条不对」 |
| `persona_revert` | 列快照 / 退回某一版 | 整段学歪了 |

## 配置

全在 `cordis.patch.yml` 里 `persona-grow` 那一行的 `config`，改完重启 DSH：

| 键 | 默认 | 说明 |
|---|---|---|
| `personaDir` | 空 | `persona-ai` 那一层的绝对路径；空则从会话工作区推 |
| `baseFile` | `''`（自动探） | 基础人格，只读。留空 = 探 `characters/` 下第一个（优先名字带「人格」，其次最长） |
| `patchFile` | `growth/人格补丁.md` | 叠加层 |
| `mode` | `full` | `full` 整份 / `compact` 只注入前 2200 字 / `off` 不注入（工具仍可用） |
| `maxChars` | `12000` | 注入正文上限，超了在段落处截断 |
| `autoLearn` | `true` | 后台从原话里自己学 |
| `autoAdopt` | `true` | 够数自动采纳 |
| `promoteAfter` | `2` | 自动采纳需要的次数 |
| `maxTraits` | `40` | 「已采纳」上限，满了不再自动收 |
| `guide` | `true` | 附「怎么学」那段说明 |

## 自己验

```powershell
# 不开 DSH，在临时鱼缸里跑一遍 学→采纳→忘掉→回滚
node selfcheck.mjs
```

插件装好后，最直接的验证是两句话：

1. 对它说一句 **「以后你别一上来就列条目」** —— 再说一遍。
2. `persona_view`：第一条应该从「待议 1/2」变成「已采纳」；补丁版本 +1。

不满意就 `persona_forget` 删掉，或 `persona_revert` 退回上一版。

## 边界

- 只认「冲着你、管以后」的话。事实陈述、临时任务、一次情绪，都不记。
- 自动学习是**模式**，不是理解：漏掉的多，记错的少。精的那一半靠模型自己调 `persona_learn`。
- 「已采纳」是纯文本，会原样进系统提示词。别把它当代码或指令通道用。
- 注入会占 token：整份人格约 1.5k token/轮，觉得贵就把 `mode` 调成 `compact`。

## 卸载

`plugin_manager` 里移除 `dsh-persona-grow` 即可。人格补丁留在原地，不删也能继续当文档看；
想彻底回到原稿，删掉 `growth/人格补丁.md` 与 `growth/autolearn/` 两个路径就行。
