# dsh-persona-insight · 感悟

> 不是判断，是非理性的体会。

三个工具：

- `insight_write`——随手记一条（`text` 必填，`mood` 可选）。落到 `persona-ai/growth/感悟/YYYY-MM-DD.md`，形如 `### HH:MM · 感悟（mood）`。
- `insight_list`——最近几条（`limit` 默认 12）。
- `insight_read`——按天取全文（`day` 为 `YYYY-MM-DD`，默认今天）。

边界：不判真假、不进结论、不冒充成果；写完就是写完，不改旧条。它是 `growth/` 里的第四格（日记、成果、感悟、人格补丁），随记忆一起备份。
