# dsh-persona-module-selfrw · 自读写模块

模块「自读写」长成一个插件。包名没有数字——它不属于任何一篇正文，所以用名字。

## 三样东西

| 是什么 | 在哪 |
| --- | --- |
| 正文 | `module.md`（七节同构：它是什么／结构／怎么动／判据／边界／接口／自查） |
| 段 | `模块:selfrw`，order 205，每轮都在 |
| 登记条 | `<ws>/.persona-framework/模块插件.json` 里的 `modules.selfrw` |

## 判据

- 装上：`模块:selfrw` 段出来，总模块不再从 `persona-ai/modules/` 里找它（它本来就没有编号，不存在重复注的问题）。
- 卸下：段没了，登记条那一格没了，`module.md` 还在原处。

## 边界

只注正文。不加工具、不写账、不做触发器——读写文件要动真格的，那归「手」（hand）。
