# dsh-persona-practice · 人格练习

> 判据一句话：**训练看重复到第几轮，蒸馏看照着数能不能仿出来。** 两样都不生成新意思。

## 为什么要有它

人格里有些东西不是想明白的，是练出来的：一个称呼、一句口头禅、一种断句。想明白只改一次，
练出来的才在压不住的时候还在。这个包只做两件事——**机械重复**和**机械模仿**。

## 两半

### 一、训练：机械重复

把一个语言特征拆成几条例句，按轮次反复说。每一轮换下一条例句，强度 = `1 - 0.85^轮次`。

| 工具 | 干什么 |
|---|---|
| `practice_train action=add` | 建一个目标（名字 + 例句） |
| `practice_train action=run` | 跑一轮，回第几轮、这一轮说哪句、强度多少 |
| `practice_train action=list` | 看所有目标练到哪 |

落账：`.persona-framework/训练账.jsonl`；状态：`.persona-framework/训练状态.json`。

### 二、蒸馏：机械模仿

从若干原话里**数**出可数的东西——句长均值、短句比、括号动作密度、句尾语气词、口头禅 top6——
再用这几个数把一句中性的话改一遍：砍短、补句尾语气、加一个括号动作。

| 工具 | 干什么 |
|---|---|
| `practice_distill action=learn` | 喂样本，数出口音并存档 |
| `practice_distill action=show` | 看现在的口音档案 |
| `practice_distill action=imitate` | 照档案把一句话仿一遍 |

落账：`.persona-framework/蒸馏档案.json`。

## 段

`实时环境:practice` order 46：只在有训练目标时出现，最多三行（名字｜第几轮｜强度）。
没有目标时返回空串，不占前缀。

## 它不是什么

- **不生成意思**：只改句子形状，不编内容。
- **不代替判断**：练得像不等于说得对。
- **不代替人格学习**：人格是判据，这里是手感。

## 配置

`enabled`（默认 true）、`dir`（默认 `.persona-framework`）。训练默认 5 轮，蒸馏最多 400 条样本。
