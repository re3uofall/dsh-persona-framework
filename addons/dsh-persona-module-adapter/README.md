# dsh-persona-module-adapter · 适配模块

模块「适配」长成一个插件。包名没有数字——它不属于任何一篇正文，所以用名字。

## 三样东西

| 是什么 | 在哪 |
| --- | --- |
| 正文 | `module.md`（七节同构：它是什么／结构／怎么动／判据／边界／接口／自查） |
| 段 | `模块:adapter`，order 205，每轮都在 |
| 登记条 | `<ws>/.persona-framework/模块插件.json` 里的 `modules.adapter` |

## 判据

- 装上：`模块:adapter` 段出来。
- 卸下：段没了，登记条那一格没了，`module.md` 还在原处。

## 边界

只注正文，不替谁做决定。换不换机器、换不换宿主，是人点头的事。
