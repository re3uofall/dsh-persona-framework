# dsh-persona-vision

给只会读字的 agent 装一双**会省钱**的眼。

> **器官层的「眼」**：进两个（眼、耳）里的一个，出两个（手、嘴）里的没它。眼是**被调用的器官**——只有 `vision_look` / `vision_note`，调一次看一次，**没调用就不许说「我刚看见了」**（见 `PLAN-PLUGINS.md` 第二十一节）。

一句话：**看一屏 → 只留变了的 → 拼成一张 → 看过的落一条能翻回去的记录。**

静止画面几乎不花 token：一帧没变就不产图、不认图，只落一行「没变」。

## 功能预期（怎么算成了）

1. **先挑后认**：抓几帧 → 按指纹挑出真的变了的 → 拼一张 → 需要时才认。
2. **没变就说没变**：一帧没变就不产图、不认图，只落一行「没变」。
3. **落一条能用**：记录里带时间与来源，说得出这一屏是什么时候的样子。

**不做**：不做常开录屏；不认人、不猜身份；不把截图当真相（它只是那一刻的样子）。

## 它不重造什么

盘上已经有两套能看的东西，本包**不碰**它们，只补中间缺的那一层：

| 已装的 | 管什么 | 本包的态度 |
| --- | --- | --- |
| `dsh-vision-router`（`vision_describe` 等 14 个工具） | 把图给模型看 | 认图**默认交给它**：没配端点时本包只交路径，由你去调 `vision_describe` |
| `dsh-computer-use-win`（MCP `wincu`） | 截屏、UIA 点按 | 不碰。本包只截屏，不点任何东西 |
| `dsh-see-now` 一类 | 按变化量筛帧、多帧拼图 | 借的就是这个思路；本包的差别是**零第三方依赖**、以及**看完落盘成记忆池条目** |

所以本包只拥有三件事：**看多久 / 看哪几帧 / 看完留什么。**

## 两个工具

### `vision_look`

看一眼主屏。

- 默认看 3 秒，每 1 秒抓一帧（共 4 帧）。
- 每帧同一趟 PowerShell 里顺手算一个 32×18 的均值灰度指纹（576 个数），**Node 里不解码 PNG**。
- 相邻两帧指纹差的均值超过 `threshold`（默认 0.003）才算「变了」。
- 变了的帧拼成一张网格图（每格左上角标时间）。
- 配了 `vision.baseUrl` 就顺手认一下；没配就**明说没认**，把路径交出去。
- 一帧没变：不产图、不认图，只落一行「没变」。

### `vision_note`

把「看到一句什么」直接落成一条记录，**不截图**。适合别人给你看了图、或者你要把一句判断挂到视觉那本账上。

## 落在哪

`persona-ai/knowledge/vision/YYYY-MM-DD.md`，跟记忆池同构：

```md
# 2026-11-02 · 看到的

## 14:03 看主屏：12 帧里挑了 3 帧
- tags: 视觉, 主屏
- kind: vision
- source: capture/2026-11-02/140312
- updated: 2026-11-02T14:03:12+08:00

4 帧里 3 帧变了（最大差 8.0%）。
变了的那几帧：14:03:01 起 / 14:03:02 +3.1% / 14:03:03 +8.0%
拼图：.persona-framework/vframes/sheet-...png
这张图我没认（没配视觉端点，或这次没让认）。
```

所以 `memory_recall` 搜得到，`memory_source` 能翻回这一条——**不是另开一个池子**。

## 配置

见 `cordis.patch.yml`，几个要点：

```yaml
durationSeconds: 3      # 看几秒
intervalSeconds: 1      # 每几秒一帧
threshold: 0.003        # 变化判据；静止画面稳定判成没变
maxFrames: 6            # 最多留几帧（超了按差异大优先，不按时间）
tileWidth: 480          # 拼图每格宽度
vision:
  baseUrl: ''           # 不填 = 不自己认
  model: ''
  apiKeyEnv: ''         # 环境变量名；留空不带 Authorization
```

`vision.baseUrl` **留空是有意的默认**：认图这件事，交给已经装好的 `vision_describe`，比在这儿重造一个端点更省事，也更不容易说出「我看见了」其实没看见的话。

## 三条边界

1. **零第三方依赖。** 图像操作全交给 PowerShell + `System.Drawing`（Windows 自带）。不装 sharp / pngjs / jimp。指纹也在那一趟里算出来，不在 Node 里解码图片。
2. **不冒充看见。** 没配端点、或这次没让认，输出里就写「没认」。失败了写「没看成」，不许被读成「没什么变化」。
3. **不写内容进人格。** 只往 `knowledge/vision/` 落条目，不碰人格文件。

## 自测

```bash
node selfcheck-vision.mjs
```

只测纯函数那几块（挑帧、差分数、落账格式、输出话术）。截屏要真屏幕，留给手动联调。
