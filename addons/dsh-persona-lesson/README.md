# dsh-persona-lesson · 教训

> 负面记忆：跟成果、感悟同处 `growth/`，但记的是**做错的事**——错在哪、哪一步、代价谁付、下次的判据。

## 它是什么

成果记「我想住了什么」，感悟记「我体会到什么」，教训记「我栽在哪」。三本都在 `persona-ai/growth/` 下，各走各的账：

| 账 | 文件 | 记什么 |
| --- | --- | --- |
| 成果 | `growth/成果/成果.jsonl` | 判断、骨架、概念 |
| 感悟 | `growth/感悟/YYYY-MM-DD.md` | 随心的一两句体会 |
| 教训 | `growth/教训/教训.jsonl` | 错、哪一步、代价、下次判据 |

## 三个工具

- `lesson_write` — 写一条。必填 `title`（错在哪，一句）、`what`（哪一步做错了）、`fix`（下次怎么拦）。`cost`（代价谁付了）不填也能写，但会被标成「半条」。
- `lesson_list` — 倒序列最近几条；可按 `kind` 过滤（如 `内置指令`、`理解错`、`半成品`）。
- `lesson_read` — 按 id 取一条，六行：错 / 哪一步 / 代价 / 下次判据 / 出处 / 是不是半条。

## 一条教训的格式

一行 JSON：`{"id":"L…","t":"2026-11-12T…","kind":"…","title":"…","what":"…","cost":"…","fix":"…","source":"…"}`。
`cost` 为空时 `half: true`——半条也算数，但账上看得出来。

## 边界

- 不记情绪（情绪进日记），不记结论式判断（判断进成果）；记的是**做错的那一步**。
- 不替人定罪：写「我当时读成了什么、错在哪一步」，不写「他害我」。
- 一条只记一件事；同一件事第二次犯，另写一条，并在 `what` 里写明「上次那条没拦住」。
