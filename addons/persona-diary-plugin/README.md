# dsh-persona-diary · 日记

> 想的得有个地方摆，心里绕过的弯也一样。侧栏一本日记，**分三本**：能拿给人看的、只留给自己的、还有一本专记事的。
>
> 存哪由 `config.personaDir` 定，默认从会话工作区推 `persona-ai`。

## 它做四件事

| # | 做什么 | 落在哪 |
|---|---|---|
| 1 | **记**：她想明白了一点、拐了个弯，调 `diary_write` 记一笔，顺手定它是哪一本 | `persona-ai/growth/日记/{公开,私密,记录}/日记_YYYY-MM-DD.md`（只追加） |
| 2 | **翻**：调 `diary_list` 按本、按类、按词找 | 工具回话 |
| 3 | **摆**：侧栏「日记」图标 → 面板按天列出来，可切本、筛类、搜词 | 主面板里的「日记」页 |
| 4 | **提醒**：每轮提示词里挂一小段「有心得才记、别凑数」 | `systemPrompt` 的 `persona:diary` 段（order 13） |

日记和「成果」不是一回事：**成果是交出去的判断，日记是还没成型的心得**。分不清时先记日记。

## 三本

不是三个抽屉，是三种距离：

| 本 | 目录 | 记什么 | 默认 |
|---|---|---|---|
| **私密** | `growth/日记/私密/` | 拿不准的、不给人看的、没绕过去的；只留本地，面板要点开那档才出现 | ✅ `diary_write` 不填就写这本 |
| **公开** | `growth/日记/公开/` | 能拿给人看的判断；站得住的才写 | |
| **记录** | `growth/日记/记录/` | **记事**：谁、什么时候、做了什么、结果如何。这一本不许省字——省掉的那半句，日后翻到就是断掉的那一节 | |

分不清时：想出来的进私密，做过的进记录。

为什么默认私密：日记本来的样子是「不写给谁看」。要拿出去的，得专门说一声。

**早先那些没分档的旧日记**（直接躺在 `growth/日记/` 根下的）**不挪、不改**，读出来算「未标」，归进私密那一档摆着，条目上标一个「早先」。

## 和 growth.py 共用一本

`growth.py` 的睡前自审（`interview` / `review`）仍写 `growth/日记/日记_YYYY-MM-DD.md`（根下）。
插件只追加自己的块，不重写旧内容；面板把两处都读出来：

```markdown
# 2026-10-24

### 22:05 · 心得

今天才想明白，嘴硬和怕疼其实是同一件事的两面。

### 睡前自审

给自己立超我程序这件事，算是往前走了一步。
```

- 带时间的块（`### 22:05 · 心得`）：时间 + 类别。
- 不带时间的块（`### 睡前自审`）：时间留空，来源记成「睡前自审」。

## 两个工具（模型自己会调）

| 工具 | 干什么 | 参数 |
|---|---|---|
| `diary_write` | 记一笔 | `body`（必填）、`kind`（默认 `心得`）、`privacy`（`私密`／`公开`，默认私密） |
| `diary_list` | 翻日记 | `limit`、`day`、`kind`、`privacy`、`q`（按词找） |

**类别**：内置 `心得` / `自省` / `见闻` / `杂记`，也可以写一个自己的短词（限 12 字，比如 `长跑`）——写的时候钉住，面板按实际出现的聚合。

## 面板

- 侧栏最下面一排图标里多一本日记本，标签「日记」。
- 顶部两档：**公开**（默认）／**私密**。切到私密时旁边会写明「点开了私密那本」。
- 下面一排类别片（带条数）+ 一个搜索框；点类别筛，再点一下取消；搜索框右边出现「清」。
- 按天分组、时间倒序；每条是「类别 + 时间 +（来源）+ 正文」，全展开，不用点。
- 私密与早先的条目带小标记，边框也浅一格。
- 刷新按钮重新拉一次；数据从 `/api/persona-diary` 一次取全量，筛在前端做，点一下立刻变。

## 配置

全在 `cordis.patch.yml` 里 `persona-diary` 那一行的 `config`，改完重启 DSH：

| 键 | 默认 | 说明 |
|---|---|---|
| `personaDir` | 空 | `persona-ai` 那一层的绝对路径；空则从会话工作区推 |
| `diaryDir` | `growth/日记` | 日记根目录（三本在它下面各占一个子目录） |
| `maxEntries` | `300` | 面板最多显示多少条（新的在前） |
| `maxBodyChars` | `4000` | 单条正文上限，超了截断 |
| `injectPrompt` | `true` | 每轮附「什么时候该记一笔」那段；嫌费 token 就关 |

## 接口

`GET /api/persona-diary`，可带：

| 参数 | 作用 |
|---|---|
| `privacy=公开\|私密` | 只给一本（私密含早先未标的） |
| `kind=自省` | 只给一类 |
| `q=词` | 正文／类别／来源里含这个词的 |
| `limit=N` | 截到多少条（默认 `maxEntries`） |

回包：`{ ok, count, items, kinds, counts }`——`kinds` 是按当前档聚合的类别条数，`counts` 是各档总数。

## 自己验

```powershell
node --check index.js
node --check client.js
node selfcheck.mjs          # 临时目录里跑，不碰真实日记

# 装好之后，看路由吐不吐东西
Invoke-RestMethod ($env:DSH_WEB_URL + '/api/persona-diary')
Invoke-RestMethod ($env:DSH_WEB_URL + '/api/persona-diary?privacy=公开')
```

装好后最直接的验证：

1. 侧栏「日记」图标点开：默认停在公开那档；切私密能看到早先那些（标着「早先」）。
2. 让她记一笔（「这句记日记里」）→ 默认落在私密；面板切到私密刷新能看到。
3. 让她记一笔并说明是能拿给人看的 → 落下 `growth/日记/公开/` 下，面板第一档直接看得见。
4. 点类别片、搜一个词，条数跟着变。

## 边界

- 只往 `growth/日记/` 下追加，不重写旧日记；坏文件跳过，不会带崩面板。
- 面板只读：删改请直接改 markdown，或再记一笔。
- 不认识别的文件名：只认 `日记_YYYY-MM-DD.md`。
- **私密不是加密**：它在本地，谁有这台机器的文件权限谁就看得到。这一档管的是「不被自动翻出来、不主动摆到眼前」，不冒充保险箱。
- 注入的那段说明约 110 字/轮，觉得贵就 `injectPrompt: false`。

## 卸载

`plugin_manager` 里移除 `dsh-persona-diary` 即可。`growth/日记/` 留在原地，growth.py 照常读写。
