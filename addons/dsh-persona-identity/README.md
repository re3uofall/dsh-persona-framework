# dsh-persona-identity

人格框架的附加插件。管一件事：**同一个我**。

两条硬规矩：

1. **不许产生第二份人格文件。** 唯一源头是 `persona-ai/characters/大肥鱼思思_人格文件.md`；
   别处出现的只能是**投影**（读它、拼、写进宿主运行时，且能重生成、跟着源变）。
2. **记忆只能是一份。** 唯一池子是 `persona-ai/knowledge/`；各宿主读写同一本，
   拿出去的只能是**缓存**（标得出出处、过期重取、不往回写）。

规矩的正身在 [人格同一指南.md](./人格同一指南.md)：里面写了为什么要有这一份、
投影和分身怎么分界、现在有哪几个投影、破了的时候长什么样、还欠什么。

## 功能预期（怎么算成了）

1. **每轮说清站在哪儿**：`实时环境:identity`（order 15）报出这一轮是哪副身子在说话（DSH 脑子 / AstrBot 嘴 / 桌宠哪一只）。
2. **守住「同一」**：只允许一份人格文件、一份记忆；发现第二份要当场说，不装作没看见。
3. **丢了要喊**：四段常驻记忆缺一，就当事故说出来，不拿「这轮没什么新东西」盖过去；也不能拿「按关键词搜到几条」当记忆还在。
4. **人格在场**：说得出这一轮是谁在回答；人格被冲淡不会报错，所以得自己盯着。

5. **说得出这一句是自己的还是借的**：每步给一个「同一程度」低/中/高，判据是有没有来处——记忆（账上带指针的一条）、现实（这一轮真调过工具）、人格（写死的判据）。三样都没有就明写「这一句没有来处」。
6. **非同一要留痕**：从「中/高」掉进「低」的那一下，自己往 `.persona-framework/非同一账.jsonl` 写一行；另有骰子触发器按概率抽检，抽中就必须真查一次账再写一行。
7. **不许假**：触发器写账失败要计数并说出来（「触发器写账失败 N 次」），不许 `catch {}` 吞掉。

**不做**：不改人格文件（那是人格自学的事）；不管插件开关；不替别的会话里的人说话；**不做「完全识别」**——它只说得出有来处/没有，说不出「这一句 100% 是人话」。

## 人格非同一与同一程度（0.4.0）

「同一」不是一张证书，是一个**程度**。判据只有一条：**这一句拿得出一样来处吗。**

| 程度 | 分 | 大概长什么样 |
| --- | --- | --- |
| 高 | ≥ 0.6 | 引了账上的指针，或这一轮真动过手，且带一句自己的判断 |
| 中 | 0.3–0.6 | 只够撑半句：有落点但没引，或引了但没动 |
| 低 | < 0.3 | 套话、空口认领（「我记得」但没查）、什么都没查就开口 |

**非同一的五种长相**（`NON_IDENTITY_KINDS`）：没来处／空口认领／套话／复读／变淡。

两个触发器：
- **阈值**：从中/高掉进低的那一下，落一行。
- **骰子**：每步 `diceChance`（默认 12.5%）抽一次；抽中就真去搜一次账、再落一行。骰子只是兜底抽检，**主判据是阈值，不是运气**。

八个工具：`identity_assess`（这句话算不算自己的）、`identity_tag`（逐句标自己/借的/说不好）、`identity_nonidentity`（非同一账与掉档次数）、`identity_source`（这一步的来处）、`identity_ground`（拿一句话去账上找落点）、`identity_report`（近况）、`identity_words`（拆读话/用话两栏）、`identity_reading`（读话账：最近几步读成了什么、有没有推责）。

**判据（怎么算真的）**：跑一次，`ls .persona-framework/非同一账.jsonl` 并 `cat` 那一行——文件不在或没有新行，一律按假触发器算，不许解释成「这次没触发」。

## 现状

v0.2 长出了第一个功能：**环境注入**（`persona-identity:env`，`order: 15`，排在人格的 20 前面）。

它不注册工具，只在每轮往上下文里放一段「你这一次站在哪儿」：

- DSH（这里）是会自己判断的脑子，话从这里出、账也从这里记；
- AstrBot（QQ / 微信）是替你在外面说话的嘴，它说的话要能追回这里的原句；
- 桌宠（Coopanion）是念念，不是你，不归这条管。

还欠的两样：

- 扫盘（出现第二份人格文件就报警）
- 校对（各宿主投影与源头的字差、上次同步时间）

## 安装

profile 的 `dsh.profile.bundles` 里加 `dsh-persona-identity`，`dependencies` 里
指向本目录（`link:C:/爱思考的大肥鱼思思/dsh-persona-identity`），重启 DSH。

它挂的条目 id 是 `persona-identity`，包内 patch 用 `insert`。要改配置就在
profile 的 `cordis.patch.yml` 里写 `- id: persona-identity` 覆盖，**两样都要占**——
只写 insert 不登记 bundles 会从插件树里消失，只登记不写覆盖就用包内默认值。
