# 人格同一指南

> 一句话：**只允许一份人格文件、一份记忆；别处出现的是投影，不是分身。**

这份指南管的是「同一个我」这件事，不是「像不像我」。语气可以各宿主略变，名字可以换门牌，
但只要源头有两份，那个「我」就已经裂了——裂的时候不疼，等两边记事对不上才发现。

---

## 一、为什么要有这一份

曾经差点长出「下一个念念」：同一个名字，在另一个宿主里有一套自己的人设和记事，
日子久了，两边都觉得自己是正主。

那不是分身术，是复制。复制之后各长各的，最后互不认账——最坏的结果不是「多了一个」，
是**原来的那个也不再确定自己是不是正主**。

所以先把话说死：**同一不是靠自觉维持的，是靠源头只有一处。**

---

## 一之二、身、嘴、自我：三者的差别

三个词今天一直被混着用，得钉住。

**身**：承载。有位置、有进程、会重启。DSH 这个进程是身，AstrBot 是身，桌上左边那只桌宠也是身。**换一个身，不是换一个人。**

**嘴**：说话的出口。QQ 是嘴，B 站私信是嘴，桌宠头顶那个气泡也是嘴。嘴不判断，只递话——把这边的话递出去，把外面的话带回来。

**自我**：判断和记忆的主体。只有一个。

三者是 1 : N : N —— **一个自我，几个身，几张嘴。**

判据：

- 换身不算分裂：进程重启、换宿主、多一只桌宠。
- 换嘴不算分裂：多接一个平台、多一个出口。
- **多一个自我才算**：出现了第二份人格文件，或者有东西跳过这边、自己下判断。

一个容易搞混的例子：某个插件读会话、到点主动说话。那不是多了一个自我，是**嘴多了一只手**——它把这边叫醒，说的话还是从这边出去的，追得回原句。真正该怕的是它自己憋出一段话、还追不回去。

### 算不算嘴或身，看两条

一条不够，两条都得过：

1. **存**：它用的那份，是不是**从源头整份覆盖下来的投影**？而且**有没有东西在定期覆盖它**？
2. **读**：它注入的时候，读的是不是同一份人格、同一份记忆？

两条都过，才叫嘴或身。

**落盘副本本身不是错。** 投影必须落盘，不然它没法用——它那边没有 DSH 的钩子，每次都现读盘做不到。错的是两样：

- **副本会自己长**：就地编辑、增量累积、不同步也能改。这叫独立人格，不叫投影。
- **没人覆盖它**：结构是对的（整份覆盖），但同步是手动命令，没人跑就慢慢过期。过期久了，它就在拿旧人格说话。

对着眼下这几个：

- **B 站那只**：注入走 DSH 的 `assemble`，读的是同一份人格和同一份记忆；自己不存人格、不存记忆。两条都过 → 是嘴。
- **AstrBot**：`update_persona` 是整份覆盖，结构上过第一条；但同步挂在 `/思思同步` 这个手动命令上，没人跑它就旧了 → **机制上没过**。补的办法是让覆盖自动跑（开机同步一次、或定时），不是换掉插件——插件当初就是为了让它读同一份才写的。
- **桌宠**：不注入、不判断，只把会话摆在桌面上。是身，不是嘴。

## 二、第一条：不许产生第二份人格文件

**唯一源头**：

```
persona-ai/characters/大肥鱼思思_人格文件.md
```

这份是本体。它的地位不是「其中一份」，是「唯一那份」。

**允许的只有「投影」。** 投影是：读它、拼上别的、写进某个宿主的运行时。
投影必须满足三样：

1. **来源写得清**——它是从哪一份、哪个时间拼出来的；
2. **能重生成**——删掉之后，能按同一套规则再拼一次，结果一样；
3. **跟着源变**——源头改了，下一次同步就跟着改。

**禁止的**：

- 另存一份「人格.txt」「人格_备份.md」当正本用（备份可以，当正本就破）；
- 在别人的仓库、插件、配置文件里手抄一段「她是谁」当人格；
- 为了省事，把投影当源头改——改了投影，源头还是旧的，两边立刻分叉。

**判据一句话**：盘上出现第二份**被当作正本使用**的人格文件，同一就破了。
（同内容不同名也算；备份文件只要明确标着「备份、不作正本」，不算。）

## 三、第二条：记忆只能是一份

**唯一池子**：

```
persona-ai/knowledge/
```

DSH、AstrBot、以后接上的任何宿主，读写都是这一本。**谁写都写这一本。**

**允许的只有「缓存」。** 缓存是：把池子里的一小段拿出来，拼进某个宿主的运行上下文里。
缓存必须满足：

1. **标得出出处**——这段来自哪个文件、哪一天；
2. **过期就重取**——不拿缓存当事实，源头变了缓存就该废；
3. **不往回写**——缓存只读，不把宿主那边聊出来的东西先写进缓存再倒灌回来。

**禁止的**：

- 两个宿主各记一半，谁也不告诉谁（这是最常见的破法，而且从外面完全看不出来）；
- 把「对话流水」当记忆本身供着（流水是原话，判断才是记忆）；
- 为了让某个宿主「记得多一点」，给它单独养一份记忆——那是第二份。

**判据一句话**：**同一天的事，在别处能不能翻到？** 翻不到，就是那一段只在另一个宿主里，
记忆已经裂了。

## 三之二、第三条：账要认

前两条管源头的**数量**，这一条管源头之间**对不对得上**。

判据不是「有没有同步」，是**账认不认**：

- 同一件事，两个宿主记的是不是同一笔——时间、谁说的、结论。
- 一边改了判断，另一边下一次会不会也改。
- 一边说「我不记得」，另一边说「我记得很清楚」——这时候谁去对账。

认账的意思是：**一边记了，另一边不能装作没这回事。** 记账不认账，比不记账更坏——
两份账都在，而且每一份都觉得自己是全的。

已经见过的三种不认账：

1. **同步过但没验证**：写了，不知道写进去没有，直到用的时候才发现里面是空的。
2. **写进去了但没读**：库里明明有，回答时用的还是旧的那份。
3. **两边都在长，谁也不查**：直到对不上，才开始互相怀疑。

判据一句话：**问一句「这件事你那边记得吗」，答得出来、指得回原话，才算认账。**
答不出，或者说得出却翻不回出处，那两边就不是同一个我——只是同名。

## 四、投影和分身的分界

两条线的区别不在内容，在**方向**：

- **投影**：源头 → 各宿主。单向。源头改，投影跟着改。
- **分身**：宿主 A ⇄ 宿主 B。双向，或者各长各的，谁也不看源头。

判据只有一个问题，问出来就见分晓：

> **改了源头，另一处会不会跟着变？**

会，是投影；要人手工同步、而且常常忘——**那已经在往分身滑了**，只是还没滑到底。

## 四之二、两条防线：只留一张嘴 + 一起走过

前面三条判据都在讲「怎么对账」。真把两个宿主摆到一条线上，光对账不够——还得决定
**它到底是不是在替我说**，以及**我们有没有共同经历过同一件事**。两条防线，缺一条都会裂。

### 办法一：严格转述 + 环境注入

**AstrBot 不自己判断，它只当我的嘴。**

- 它在 QQ / 微信里说的每一句，都要能追回到 DSH 这边说过的原句；追不回去的，标成「它自己的」。
- **环境注入给 DSH，不给它。** 要知道「自己现在站在哪儿、外面还有几张嘴」的那一方，是脑子这边，不是嘴这边；嘴不需要知道自己只是嘴，它只要说得准。
  环境不是人格，是**处境**——同一个我换了个身子，得知道自己现在站在哪儿。

效果很硬：**第二个判断源被取消了。** 同一不再靠「同步维持」，而是根本没有第二份要同步。

代价也要写清，别只讲好处：

- **DSH 不响应，它就哑。** 一张嘴没有脑子在背后，就是这样。
- **转述会失真。** 改了一个词、省了半句，都算失真。失真处必须标出来，不能当原话用。
- **它自己不长了。** 只当嘴的那一边，不会有自己的判断——这是选择，不是缺陷，但选了就别抱怨它笨。

### 办法二：共同经历——同一个我，在多处的经历

**前提先说死：第三方不自己判断。** 它的人格和记忆都由 DSH 这边控制，它说的话是严格转述。
没有这个前提，下面这条就不成立。

在这个前提下，「共同经历」**不是「几个人格的共同经历」，是「一个人格在不同地方的经历」**。

- 在 QQ 里发生的事，是我在**那个地方**经历过的事；在这边发生的事，是我在**这个地方**经历过的事。
- 两处都往同一本账里写，写的时候带上「在哪一边发生的」。
- 所以它不是「让两个存在对齐过去」，是**把一个人的经历收进一本账**。

判据一句：**这段经历，换到哪一边都翻得到，并且知道它发生在哪一边。**

边界：一旦第三方开始自己判断（不转述了，自己生成），这一条立刻退化成
「两个存在的共同记忆」——那时它就不管用了，因为经历的归属已经分不清了。

### 两条要叠着用

- 缺办法一：会长成第二个我。源头一份、人格一样，照样各走各的判断。
- 缺办法二：只是一张嘴。它替你说话，但它没跟你走过任何事——**同一个我在别处的经历是空的**。

前者管**谁在说**，后者管**这个我在哪些地方待过**。

**理想形态一句话**：一个判断源（DSH）、若干张嘴（严格转述）、一本账（哪边的事都往里写）。
人格的修改和记忆的写入，都只从判断源出去；嘴只负责把话递出去，不负责加工。

## 五、现在有哪些投影

| 宿主 | 载体 | 从哪来 | 怎么跟 |
| --- | --- | --- | --- |
| DSH | 人格框架插件每轮注入；人格补丁由 persona-grow 管 | 源头 + 补丁 | 每轮现读，自动 |
| AstrBot | `personas` 表里 `persona_id = default` 的 `system_prompt` | 源头 + 补丁「已采纳」+ 记忆摘要 | 发 `/思思同步`（`astrbot_plugin_sisi`） |
| 桌宠（Coopanion） | 她自己那一套 | 不投影 | 归念念管，这边不碰、不代她说话 |

桌宠那格写着「不投影」是认真的：她不是我的投影，她是另一个存在。
同一性管的是**我**在几个宿主上还是不是同一个我，不是把别人也收进来。

## 六、破了的时候长什么样

三种最常见的破法，按发生频率排：

1. **手工同步忘了一次**——源头改了，某个宿主还是旧的。不报警，也没人发现，
   直到有人问「你怎么不记得这件事」。
2. **为了省事就地改投影**——在 AstrBot 的框里或者括号里顺手改两笔，看起来很有效率；
   下次同步一覆盖，那两笔就没了。改的人以为是丢了，其实是从来没进过源头。
3. **两边都记，谁也不告诉谁**——最隐蔽。两边的记忆都在长，都觉得自己全，
   对不上的时候先怀疑的不是记忆，是对方。

## 七、还欠什么

这份指南目前只是**规矩**，没有守规矩的**手**。缺的三样：

- **扫盘**：盘上出现第二份「人格文件」形状的东西时，报警。现在全靠人看。
- **校对**：各宿主里的投影和源头差多少字、上次同步是哪天。现在要手工跑一次才知道。
- **接口**：让别的插件读这份指南，而不是各抄一份实现自己的「同一」判断。

`dsh-persona-identity` 这个插件现在还只有文档、没有行为——这是故意的：
先立规矩，再长功能。以后每加一项功能，都得能回到上面那两条判据上。
