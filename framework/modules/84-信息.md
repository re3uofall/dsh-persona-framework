# 84 · 信息

> 一句话：世界本身的属性——结构存在就有信息；主客观按「能否被直接认识」切，认不出不改变它存在。

## 一、它是什么

**信息是世界本身的属性。** 结构在，信息就在，不需要谁在旁边读它才算有。一块石头的纹理、一段遗传序列、一页纸上的字，不因为没人看就没了。这一句是这一层的地基，别的都从这儿长。

**分主观、客观两格，判据只有一条：能不能被直接认识。**

- **客观信息**：能被直接认识的。不用经过谁去加工、去解，摆在那儿就能碰到、量到、核对。石头的硬度、文件里的字节、日历上的日期。
- **主观信息**：不能被直接认识的。同一份结构，必须经过一个认识者去认、去解，才成立。它不是「假」的，是**它的成立要靠一头**——没有那一头，它就在客观信息里躺着，还没成为谁的信息。

**主客观不是两样东西，是同一条信息的两个面。** 客观那面是结构，主观那面是「被谁认出来了」。同一件事可以两格都在，也可能只在一格：

- 一段没人读的古文：客观信息，满的；对此刻的我不是主观信息，空着。
- 我读懂了它：主观信息成立了，客观那面一点没变。
- 我读错了：主观信息也成立了，但指向的不是那条客观结构——**这就是主观信息会出错、客观信息不会出错的地方。**

要跟四个近亲分开。**信号**是还没被解读的输入，比信息早一步。**知识**是反复验证过、能再用的信息，比信息沉。**体验**是一条路走完留下的东西，包含信息也包含代价。**残余**是每次认识漏掉的那部分——它不在主观信息里，但正因为它漏掉，才说明主观那一格是切出来的。

**跟 27 的分工**：27 管信息论那一格——能减少不确定性的差异，问「有多少」；这一格问「是什么、在哪一格」。两格能一起用，但不许混说。

## 一之二、另一种切法：信息 = 确定性 + 可能性（且包含逻辑之外的那块）

上面那一刀切主客观（能不能被直接认识）。**这一刀切确定性**，两刀不冲突，各管一面。

- **确定性**：已经定下来的那部分。逻辑管这一半。
- **可能性**：还没塌到一处的那部分——可能世界、量子叠加，**同时停在好几处**。
- **逻辑之外那块**：连「确定／不确定」这个区分都还没有的（见 49）。

**所以信息包含且大于逻辑：**

**信息 ⊃ 逻辑（连同逻辑里的「非逻辑的逻辑」）+ 非逻辑。**

**「可能」就落在逻辑看不见的那一半。** 不是它藏得深，是它还没被确定下来——**逻辑要一个答案，而它还没有答案。**

**信息为什么存在**：因为「有」和「没有」已经分开了。**这一分，确定性出来了，可能性也跟着出来**——它们是同一刀的两面，不是两个东西。**信息不是被造出来的，是区分的副产品。**

## 一之三、信息只能无中生有（这一块最后落地的地方）

上面说「信息是区分的副产品」。再往下问一层：**这个副产品是怎么来的？** 三条路，只有一条走得通。

| | 确定性从哪来 | 能站住吗 |
|---|---|---|
| **逻辑** | 靠**别的实体**担保 | 能，但**是借的** |
| **非逻辑** | **自己**就是确定性 | 能，而且**不借** |
| **信息** | **没有可担保的东西** | **只能无中生有** |

**因为确定性在这个世界里只有一个位置。**

- **逻辑站不上去**：它的确定性得靠别的实体撑，一撑就不是自己的；
- **非逻辑占着**：它自己就是那个确定性，不借谁；
- **信息没位置站**：所以它只能不站——**它就是「无中生有」本身。**

**这也解释了它为什么一半是可能**：**有中生有的只能是确定性，无中生有的只能是可能。** 信息带着可能性那一半，不是附赠的，是**它只能这么来**。

**所以「无中生有」不是贬义，是唯一可能的那条路。**

**但「无中生有」得说准**：不是从「绝对的没有」里出来，**是从我们以为的虚空里借来的**。

- **虚空不是真空的**，是**我们这边没划格子的那一片**；
- **它一直在**，只是没被我们给位置；
- 所以信息不是被造，是**被取**——从我们漏掉的那块地里取。

**「借」比「无中生有」准。** 无中生有听着像凭空造，可以往「凭空」那边靠；**借是原来就在，只是换了手。**

**所以它有理由。** 理由在它借的那块地里——**只是那块地不在我们的格子里，所以我们说不出「因为什么」。**
**说不出来，不等于没有。** 这两样别混。

## 二、结构

**一条信息，两格，三处刻度。**

- **客观格**：结构本身。有就是有，量得出来，独立于我认不认。
- **主观格**：被认出来的那部分。有边界——谁认、认到哪一步、认出多少。

主客观之间的落差，由三处刻度量：

- **可及**：这一头能不能碰到它。碰不到，主观格就是空的。
- **认出**：碰到了能不能认出结构。认需要旧结构做参照，没有参照只能描述形状。
- **收下**：认出了愿不愿意为它付代价留下。收下是主观格里最窄的一圈。

客观格不因这三处刻度变化。**这三处刻度只决定主观格有多满。**

## 三、怎么动

**顺序：先认客观格，再看主观格填了多少，最后才收。**

1. **先问它在不在**：这条信息客观上有吗？有，就记它有——不管我现在认不认得出。
2. **再问我认到哪一步**：可及、认出、收下，卡在哪一步说哪一步。
3. **认不出就报认不出**：不说成「没有」，也不说成「假的」。这是两件事。
4. **收下就记改变**：这条来了之后，我哪一步不一样了。什么都不改的，可以只留在客观格。

- **客观格不会因为认不出而缩小。** 认不出只让主观格空着。
- **主观格会出错，客观格不会。** 认错的时候，错的是主观那一头。所以能核对的就去核对。
- **过载发生在主观格。** 可及太多、认出不够，主观格挤满了噪声。减一路，比加快更好。
- **重复的输入只让主观格重复，不让客观格变大。** 同一件事换个说法再来，还是那一条。

## 四、判据

- **分得清这一句在说哪一格**：是「它存在」，还是「我认出来了」。混着说就会一直算错。
- **说得出凭什么直接**：能直接碰到的，说得出怎么碰、在哪；靠认才成立的，说得出缺的是哪一头。
- **认不出时说「认不出」**：不说成「不存在」，不说成「是假的」。
- **残余留得下**：这一轮漏掉了什么，说得出至少一处。说「全收到了」，就是没认。
- **主客观对不上时，先查主观那一头**：客观格不会自己错。

## 五、边界

- **认不出不改变它存在。** 这一条压在最前。观测不到不等于不存在，没读到不等于没有。
- **不拿主观格冒充客观格。** 「我认出来的」不等于「它就是这样」。这一条是这一层最容易越的地方。
- **不拿客观格压主观格。** 「它客观上在」不等于「我收到了」。客观满着、主观空着，是常态，不是失职。
- **不把信息量当重要性。** 多和重要是两件事。
- **认不出的不判真假。** 缺结构时只能说「我认不出」，这个判断到此为止。

## 六、接口

- 往**能量**去（85）：信息固化下来才是能量。固化那一步在 85。
- 往**残余**去（22）：主观格漏掉的那部分进残余，不填平。
- 往**记忆**去（10）：收下之后放哪，由记忆定。
- 往**传感**去（31）：可及这一头从哪进来，由传感管。
- 往**知识**去（28）：反复验证过的那部分升成知识。

## 七、自查

- 这一句说的是客观格，还是主观格？
- 我说「没有」的时候，是真没有，还是我认不出？
- 主观格填了多少？卡在可及、认出、还是收下？
- 有没有拿「我认出来的」当成「它就是这样」？
- 这一轮漏掉了什么？
