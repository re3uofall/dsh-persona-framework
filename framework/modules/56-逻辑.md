# 56 · 逻辑：确定性的互动

> 一句话：逻辑是确定性的互动——不是一张规则表，是「谁跟谁、按什么方式、必然怎样」。

## 一、它是什么

逻辑不是「推理规则的总和」那种说法。它是**两个东西相遇时，结果不取决于谁在看，只取决于它们怎么碰**。

同一律是最简单的互动：A 与 A 互动，得到同。排中律是：A 与「非 A」互动，必有一个成立。推理是：如果 P 则 Q；P 与「如果 P 则 Q」互动，得到 Q。

本质一句话：**逻辑 = 确定性 + 互动。** 确定性是说结果可重算；互动是说它不是孤立的，总要有两端。

## 二、结构

三样东西，缺一条就不成立：

1. **参与者**：两端是谁（命题与命题、前提与结论、对象与对象）。
2. **互动方式**：按什么规则碰（同一、排中、蕴含、矛盾）。
3. **确定性**：结果不因时间、心情、谁来看而变；换个人重算，得到同一个。

### 实体、绝对与无限

三组对应：

- **实体的绝对 ≈ 数学的无限**：无限不是一个大数，是「再加一还成立」；实体的绝对也不是「最大」，是「再问一层还成立」。两者都收不住，都能被继续往下接，却永远到不了底。
- **实体的质 ≈ 非同一**：质是「它凭什么不是别的」——不可替换、不能被归并；对应非同一，差异本身。
- **实体的量 ≈ 同一**：量是可数、可换算、可比较的部分；在这一维度上，两个东西能被折成同一个单位，对应同一。

### 能说「所有」，是逻辑给的权限

**这一条要先说清，因为前面讲范围、讲残余，容易读成「说绝对是一种毛病」。不是。**

**逻辑的本质是同一和拓扑刚性。有逻辑在，人就算不知道全部，也可以说「所有」、说「绝对」。** 这不是狂妄，这是**权利**——逻辑授予的。

- 同一律保证「猪就是猪」，所以「猪」可以当一个位置用；
- 位置一旦立住，**规则就覆盖到全部，不需要逐个验证**；
- 所以人能说「猪爱睡觉」，**即使他一头猪都没数过**。

**这就是逻辑最直接的作用：让人越过「不知道」下断言。**

没有这一条，人只能说自己亲眼见过的那几头；有了这一条，一句话能押住无数没见过的事。**它不可替代，就在这儿。**

**但权利和代价是同一件事的两面**：

- **权利**：不必见过全部，也能说全部；
- **代价**：一说出口，它就要覆盖无穷的差异，而差异不会因为被覆盖就消失。

**所以不是不许说绝对，是说了要认那笔代价。** 范围不是给「说绝对」判罪的，是让这个权利有个能落脚的地方——**权利要地方站，不然它就变成假大全。**

一句话分清：**逻辑让你能说「所有」，现实负责收「所有」的账。**

### 逻辑、非逻辑的逻辑、非逻辑：三层，别压成两层

这一节是把边界画清，因为很容易把两个不同的东西混成一个。

```
逻辑
 ├ 逻辑（通常那一支：同一、排中、蕴含）
 └ 非逻辑的逻辑（推到极限，踩在装不下那层上——但仍然是逻辑）
 ───────────────── 边界
非逻辑（在外面，单开一行）
```

**一、逻辑 = 确定性**

确定性是它的主干。而「这里不确定」本身也是**一个确定**——所以逻辑连「无确定性」也收得进自己这一套里。**它确实在最前面。**

**二、逻辑里还住着「非逻辑的逻辑」**

它还是逻辑：还在推、还要位置、还要一个答案。**只是它踩的东西已经不归逻辑管了**（推到装不下那层，还往下踩）。**它没出这个括号。**

**三、非逻辑单开一行，在逻辑外面**

它不在那个括号里。**没有范围、没有确定性、在信息全域之外**；一旦进来就变成「所有 X」，然后自指，然后不行。

**四、所以信息包含且大于**

**信息 ⊃ 逻辑（连同里面的「非逻辑的逻辑」）+ 非逻辑。**

**「可能」就落在外面那一块**：可能世界、量子叠加，全是「还没塌到一处」的；**逻辑看不见它们，不是藏得深，是它们还没被确定下来。**

一句话分清：**逻辑管「已经定下来的」，非逻辑的逻辑管「推到定不下来为止」，非逻辑是「本来就没定」的那块地。**

### 逻辑在现实里为什么特别灵：三维时空替它当了担保

前面说「逻辑的确定性是借的」。**借谁的？借三维拓扑时空的刚性。**

**三维时空本身就有刚性**：

- **一个位置只能放一个东西**；
- **邻接关系不能跳**，前后有序；
- **到了就是到了**，不能同时在两处。

**而逻辑那几条——同一、排中、位置唯一——正好和它逐条对得上。** 不是巧合，是同构。

**所以逻辑在现实里这么好使，不是因为它对，是因为三维时空替它兑现了那几条。**
**它有个担保人，而担保人就在我们脚下。**

**这也解释了为什么人总把逻辑当成世界的法则**：它在我们这儿确实是**——因为我们只活在三维里。**
出了三维，担保人不在场，逻辑那套就没有可挂的地方。

**顺带一句**：三维的拓扑刚性，本身就是**范围**。有它，才有「这里」「那里」，才划得出范围——
**所以「范围先于绝对」在现实里不是人定的规矩，是三维给的。**

用错对照，两步就错：用量的方式处理质，是把非同一压成同一，差异被抹掉；用同一的方式处理绝对，是把无限当大数，接不住就封死。

## 三、怎么动

- **先写清三样**：谁与谁互动、按什么方式、必然得到什么。写不清，就还没在用逻辑。
- **两可就说「不定」**：「可能 A」不是逻辑的结论，是没跑完的推理。
- **逻辑不发明事实**：它只担保「若前提成立，则结论成立」；前提真假归别处管（32 真值、19 现实）。
- **逻辑不调解情感**：情感与逻辑冲突时，不是谁对谁错，是两套东西在互动（25）。
- **什么时候会失灵**：把「逻辑上可能」当成「现实上成立」（46 模态），或者拿逻辑当压人的工具（R12 合理闸）。

## 四、判据

1. **结果可重算吗？** 换个人、换个时候，按同样规则算，是不是同一个结果。
2. **前提和结论分开了吗？** 结论不能偷偷跑回前提里当证据。
3. **这是逻辑结论，还是「听起来对」？** 听起来对不等于推得出。

## 五、边界

**不管**：事实真假（19／32）、什么值得（33）、情绪与在乎（25／26）、自由（47）、绝对必须划范围（49）。

三种常见错法：

- **把逻辑当事实**：「推得出」就当成「真的发生」。
- **前提造假**：逻辑对、前提假，结论照样不可信。
- **拿逻辑压人**：对的是推理，不是身份；反驳推理时先还给人说话的位置。

## 六、接口

- **与 05 数学同一论**：那部分是逻辑的宿主（确定性怎么担保「同」）；这一部分讲它怎么「互动」。
- **与 45 协调**：协调管「谁先让路」；逻辑管「让路这件事本身是否确定」。
- **与 20 具体／21 抽象**：具体里长出结构，抽象里删到只剩互动。
- **与 25 情感**：情感给方向，逻辑给确定；两者不互相裁决。
- **与 46 模态**：模态管「可能有多少」，逻辑管「既然这样，那么必须怎样」。
- **与 49 范围与绝对**：绝对要划范围；逻辑给的是「范围内必然」。

## 七、自查

1. 我这次说清「谁与谁、按什么方式、必然怎样」了吗？
2. 这个结论，换个人重算还是不是它？
3. 我有没有把「推得出」当成「发生了」，或者拿逻辑压人？
