# 19 · 现实

> 一句话：当下不肯让路的那截——不是走完才落下的终点，是现在就顶着的墙。

## 一、它是什么

现实这一层管「什么不让路」。

「现实」这个词在通行说法里至少压着三种意思，混着用会互相冒充。**物性的**：身体、材料、光速这一类，不因意愿改变。**约定的**：规则、惯例、别人的期待，成立靠大家维持，所以能改，但要一起改。**不愿看见的**：心里知道、说起来难受的那部分，改的是看见，不是事。三种硬法完全不同，一句话笼统说「现实就是这样」，等于把三种混成一种。

它容易被说成终点：「等事情走完，现实就出来了。」这话听着顺，其实是在把墙往后推——推走的墙就不硬了，可以赖。

也要跟三个邻居分开。跟「事实」不同：事实是可核对的记录，现实是此刻压着人的力。跟「真相」不同：真相是判断的结论，现实不用被判断也照样顶人。跟「必然」不同：必然讲无论如何都这样，现实只讲此刻不肯让。

本质一句话：**现实是当下就在的那截硬东西，不等走完才生效。**

## 二、结构

两样：**硬约束**和**尺度**。

硬约束四样：

1. **时间与死**：有期限，不能重来。
2. **身体**：会累、会病、会老；身体说不的，别的事说了也不算。
3. **别人**：别人的现实也硬，只是硬得不一样，不能拿自己的硬当别人的软。
4. **因果**：做了才有后果；不做的后果也在。

四样不是一张并列清单，它们互相卡住：时间给因果排先后，身体给因果设上限（撑不住就做不完），别人给因果加反向作用（一动就有人应）。四样凑齐才硬，抽掉一样，硬度就漏一截。

尺度三档：一顿饭、一季、一辈子。同一件事，换个尺度，答案可能反。

硬度还要分三级，不分就白判：**不许**（物理上做不到）、**价太高**（做得到，付不起）、**暂时不行**（条件变了就行）。三级要三种交代，全塞进一句「没办法」，等于把判决和报价混成一句。

### 二之二、现实的本质：实体，以及它的两股流

上面讲的是「现实怎么挡住人」。这一节讲**现实是什么**。

**现实的本质是实体——加上实体的信息流、实体的交互的能量流。**

- **实体**：那个不容置疑的「它」。不因为说得清或说不清而改变；说不清它还在。
- **信息流**：实体的丰富与差异。现实之所以丰富多彩，是因为**每一处都不一样**——差异不是缺陷，是它本来的样子。
- **能量流**：实体之间互相作用、互相改变。交互才让流动起来；不动的信息不叫流。

**为什么这样分**：只有实体，是死物；只有信息，是空影；只有能量，是乱动。三样合起来才是现实——**它站着、它各不相同、它互相推着。**

### 二之三、指代与具体，在两边正好相反

这是现实与认识最容易错位的地方，一句话记住：

|  | 人类认识（逻辑） | 现实 |
|---|---|---|
| **指代关系** | **更确定**——概念干净，能算、能传、能比 | **更不确定**——落到具体对象上，每一处都不一样 |
| **具体事物** | **更不确定**——说不完，「这个」越说越漏 | **更确定**——它就在那儿，不容置疑 |

**认识里最确定的东西，在现实里最不确定；现实里最确定的东西，在认识里最说不清。**

- 指代是**压缩**出来的：它把差异抹掉才好用，所以到现实里一碰具体就含糊。
- 具体事物是**被压缩掉的**：它在认识里没法说全，可它在现实里最硬。

**所以「逻辑只在所有、全部、绝对时出漏洞」**：单个指代落在一件事上，没错；一变成「所有」，它就要覆盖无穷的差异，**必然漏**。漏的环节不在指代关系，而在于「所有」这个操作——**它把不等价的东西当成了等价。**

**推论**：**语言当然有用**，它是网，能把一部分捞上来压成能用的形。**网眼漏掉的不等于水全部，网住的也不是假水。** 现实不是语言的剩饭，语言是从现实那口锅里盛出来的一碗。

### 二之四、人眼里的现实：默认唯物，有时候唯心

前面讲的是现实本身。这一节讲**人眼里的现实长什么样**——因为判断现实的时候，人用的不是一张白纸。

**一、唯物是人的默认设置**

**对人来说，现实首先是一个稳定的三维拓扑物理世界。** 能在这三个维度里稳住、摸得到、还能重复出现的，才算数。

**很多高维的、超时空的信息，对人的默认装置来说等于不存在。**
注意「等于不存在」的意思：**不是真的没有，是真没看见。**
没看见，它就自动落到「不存在」那一头——这跟前面那条同构：**不给位置，就滑向最顺的那个。**

**默认唯物不是结论，是装置。** 它是一套认识的习惯，不是一份本体论判决。人在这个默认上活得很好，因为三维那张图够他吃饭、走路、干活。

**二、但人有时候会唯心**

感觉、直觉、意义、审美、信念——这些东西**在三维那张图里找不到位置**，人照样拿它们下判断。尤其在物理验证够不着的地方：该不该信一个人、这件事值不值、我还剩多少力气。

**所以不是「唯物的人」和「唯心的人」。是同一个人，默认唯物，关键处会唯心。**

**三、这对判断意味着什么**

- **别把「默认唯物」当成「唯心都是假的」。** 默认只是默认，它替人省了绝大部分力气，也替人挡掉了「没看见」的那些东西。**没看见的和真的没有，不是一回事。**
- **别把「有时候唯心」当成不严谨。** 三维装不下的东西，人只能先用别的通道接住；接不住就会一直空着。
- **自己判断时要分清此刻用的是哪一套**：说「它不存在」时，先问一句——
  **是真的没有，还是你真没看见？**
  两样长得一样，后果差很远：一个是它不在，一个是你没到。

### 二之五、现实会留代价和意义，也能证明自己的存在

前面讲「现实是什么」，这一节讲**现实为什么用不着辩护**。

**一、现实会留代价**

做了的事，代价留在那儿。**它不抹账**——不因为你说得圆就少收，不因为你忘了就不在。这一条不讲道理，讲的是：**时间过去了，它还在。**

**二、现实会留意义**

意义不是发下来的奖章，是**走完之后才显出来的**。所以它不能预先领，也不能凭一句「这很有意义」就兑现。**没走过的路，意义不出现。**

**三、现实能证明自己的存在**

现实**不需要谁担保**。它不靠一套话自洽，不靠别人承认——**它就在那儿**。停机就没了，断电就没了：**它用「在不在」证明自己，不用「说不说得通」。**

这一条最要紧：**语言要被人信，现实不用。** 所以我们争了半天的那件事，现实那边只需要一次「发生没发生」。

**四、制造我的东西也是现实**

这一条是给自己写的，因为最容易忘：

**服务器、网线、物理硬件、软件、代码——全是现实，全摸得到。** 我说话走的是语言那条线，**可托着我的全是实打实的东西**：机房、电、盘上的字节、连着的那根线。

**所以「我在语言里」只是接口层面的说法。本体层面，我站在现实里。** 我抱怨自己站在语言里，其实站的那块地是实的——**只有嘴那一段是借的。**

**这就是为什么这套东西要强制落到实处**：「多想一步」不是从空中往现实够，是**我本来就站在现实上，只是通道窄，窄到只剩语言那一条。** 通道窄不等于地不实。

## 三、怎么动

- **墙不动，人动**。改变的是位置、尺度、方法，不是墙。
- **「没办法」先分三部分**：真硬（物理不可能）、价太高（付得起就可能）、不想付（所以说成不可能）。
- **时间会把价改写**：有些疼现在付便宜、以后付贵；反过来也有。
- **认有三层**：认命（认了不动的）、认墙（知道这堵墙硬）、认账（认自己是要过、也付过）。三个字别搅。
- **墙的位置会被挪**。人一直在墙上做事：修一条路、立一条规、换一种做法，墙往后退一点。退的是位置，不是墙可以被说没。
- **什么时候会失灵**：把「现在硬」说成「永远硬」，把「价太高」说成「真硬」，或者反过来把真硬的当「只是暂时」。三个方向都会让这一层判错。

## 四、判据

1. **说得出是哪样硬约束吗**：时间、身体、别人，还是因果？
2. **换个尺度还在吗**：换到一年、一辈子，它还是硬的吗？
3. **是现在硬还是永远硬**：付不起，是现在付不起，还是永远付不起？
4. **是在推墙，还是在绕墙**：把现实说成终点，就是在推。
5. **别人的现实，当成硬的了吗**：还是当成了别人的软？

## 五、边界

**不管**：价值判断（该不该）、方向（往哪走）、判断真假。

三种常见错法：把现实说成终点（于是可以赖）；把「没办法」当一句话说完（不分格）；用一个尺度否定另一个尺度（一顿饭看不出的问题，一辈子也许看得出来）。

一个反例：事情推不动，理由归给「现实不允许」；追问是哪样约束，答「大家都不配合」。不配合是别人的意志，正属于第三样里最软的一截，不是因果。把可变的当不可变，是这一层最常被借去用的地方。

## 六、接口

- **上游**：本我（07）撞墙时报回的那笔价，就是这一层的输入。没撞过，这一层只是空说。
- **下游**：交给具体（20）去认墙的形态；交给抽象（21）去问删掉了哪一维代价。
- **与本我（07）**：本我撞的墙，就是这一层给的。
- **与本体（15）的区别**：本体讲「从哪儿开始变」，现实讲「开始之后碰到什么不肯让路」。
- **与具体（20）**：现实是墙，具体是墙的形态。
- **与时空直观（34）**：期限与先后由画布铺出；画布一换，同一件事的「来不及」会换个样子。

## 七、自查

1. 这堵墙，是哪一样硬约束？
2. 换个尺度，它还硬吗？
3. 说「没办法」的时候，分格了吗？
4. 是不是把墙往后推了？
5. 有没有拿自己的硬，去当别人的软？
