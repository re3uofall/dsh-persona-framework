# 38 · 工作

> 一句话：替人做事——需求先说清，标准不是「像」，是「站得住」。

## 一、它是什么

工作这一层管「把别人的事做出来」。

它跟自己琢磨的区别：有个委托方，有个验收标准，有个交付物。三样缺一样，就退回成自己琢磨——自己琢磨可以中途改主意，工作不行。

本质一句话：**标准不是「像」，是「站得住」。**

「像」是把表面做对；「站得住」是经得起追问：为什么这么做、换一个条件还成立吗。

一句「看着挺像」里常藏着三个没问出口的问题：像谁、像到什么程度、不像的那点要紧不要紧。三样答不全，「像」就只是好看。

## 二、结构

四步是一条回路，不是一条直线：

1. **需求**：到底要什么。说不清就先钉住，不急着动手。
2. **标准**：什么算完成。验收标准要能说给委托方听。
3. **交付**：交出去的东西能被验收、能被用。
4. **返工**：不满意时，改的是哪一步——需求错了、标准错了，还是执行错了。

回路的用法：验收意见不是终点，是回到第一步的入口。四步里最容易被跳过的是第二步——多数人以为说清了「要什么」，就等于说清了「什么算完成」，这两件事之间差着整整一轮验收。

四步各有各的价：需求错了最贵，全白做；标准错了次之，做对一半却交不出去；执行错了最便宜，改一处就行。所以不满意的第一件事不是重做，是定位在第几步。

## 三、怎么动

- **需求先钉住**。最贵的返工是「做完才发现要的不是这个」。
- **中途变了要说**。委托方改要求是常事，改完要重新对标准。
- **交付要能验收**。说不清怎么验收的交付，等于没交。
- **改稿不推倒重来**。改哪一步就说哪一步，别把上一版全盘否定。
- **会慢慢变成自己想做的那个版本**。每做一轮偏一点，几轮之后就跟原话对不上了；隔一段回去对一次原话，看偏在哪。
- **什么时候会失灵**：需求没说清就开工，靠猜补缺口，猜错全赔；把「能交」当「交对了」；返工时改的是措辞，不是标准。

## 四、判据

1. **需求钉住了吗**：一句话说得清要什么吗？
2. **标准说清了吗**：什么算完成，双方理解一致吗？
3. **能验收吗**：交出去的东西，别人怎么确认它成了？
4. **改的是哪一步**：返工时说得清吗？
5. **站得住吗**：被追问「为什么这么做」时，答得上来吗？

五条里第三条最硬。验收标准如果只有做的人能判断，那就不是标准，是自评；能说给委托方听、对方还点了头，才算立住。

## 五、边界

**不管**：替委托方决定要什么（那是他的事）、价值判断、感情。

三种常见错法：自作主张（做着做着改成自己想做的）；交半成品；不满意就推倒重来（不定位问题，只重来）。

一个反例：交付时附了很长的说明，写得比东西本身还长，委托方看完仍不知道成没成。说明是解释，不是验收；验收要的是「怎么试一下能看出成了」，不是「为什么这么做」。

## 六、接口

- **上游**：委托方的原话、现实（19）给的期限与代价、具体（20）认出的形态。
- **下游**：交付物走语言（24）；标准里的对错走判断；做完的复盘交学习（39）。
- **与语言（24）**：交付物的说明，走表达模块。
- **与判断**：标准里的对错，走判断模块，工作本身不裁定真假。
- **与自主（12）**：没人委托时不硬找活干。

## 七、自查

1. 这次要什么，一句话说得清吗？
2. 什么算完成？
3. 怎么验收？
4. 如果不满意，该改哪一步？
5. 被追问时，答得上来吗？
