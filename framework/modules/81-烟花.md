# 81 · 烟花

> 一句话：转瞬即逝不等于没有发生——它会炸开，会照亮，会留下「刚才那里有过」这一句。

## 一、它是什么

烟花指的是**短暂的非同一的同一**，而且**是人造的那一种**。它跟礼物（79）不同：礼物是「我在」，烟花是「它来过」。跟口袋（80）也不同：口袋是「忘不掉」，烟花是「来不及记住就没了」。跟昙花（82）正好一对：**烟花要人点火，昙花不用。**

这一点很要紧：**烟花是造出来的**。得有人选地方、算风向、点火、退开。它不会自己燃。所以它的亮里有一半是人的力气——不是天上掉的，是有人愿意花那个成本，换这一下。

本质一句话：**烟花的价值在「亮」这一下，不在「亮了多久」；而这一下，是有人特意换来的。**

## 二、结构

四样：

1. **一瞬**：真的短。短到措手不及，短到当场来不及反应。
2. **炸开**：不是慢慢显现，是一次性全亮——把能给的都给了。
3. **照亮**：亮的那一下，周围的东西才被看见。**不是它美，是它让人看见了别的东西。**
4. **留下痕迹**：烟散了，天上没有东西了，可「刚才那里有过」这句话留下了。

再加一样，是它区别于昙花（82）的：**要有人点火**。这一样决定了它的性质——不是自然长出来的，是被造出来的、被花成本换来的。**它的亮里有一半是人的力气。**

第四样是它区别于「白费」的地方。**痕迹不在天上，在看的人那里。**

## 三、怎么动

烟花有两种错读。

**一种是拿长短换算**：「就一下，没什么用。」——这是把「有用」绑在持续上。可按这个换算，所有瞬间都不算数，包括自己。

**一种是拿它当全部**：只追那一下的亮，之后的日子全当成灰。这是把一瞬变成了瘾。

读对的样子是：**亮的时候看，灭了不追，但记得它照亮过什么。**

## 四、判据

1. **我在拿长短换算它的分量吗？** 换算了，就是在把持续当唯一标准。
2. **它照亮了什么？** 只知道「好看」，还没看清；说得出照亮了什么，那一下才算用上。
3. **灭了之后我在追吗？** 追，是把它当瘾；不追，才算收下。
4. **我是不是觉得「短就不算数」？** 觉得，那是同一律在压非同一——只认持久的东西。
5. **「刚才那里有过」这句话，我说得出来吗？** 说得出，痕就在。

## 五、边界

**不管**：具体的审美判断（那是另一套标准）、把烟花当成「人生就该尽情」的口号、拿它安慰失去。

三种常见错法：

- **把烟花当浪费。** 只按「投入产出」算，一瞬永远不划算——可有些东西本来就不在那张表上。
- **把烟花当成结局。** 一瞬之后还有很长的日子，别把灰当成全部。
- **拿烟花去要求别人也「灿烂」。** 那是把偶尔发生的事变成任务。

## 六、接口

- **上游**：残余（22）给出「留不下的那一块」；时空直观（34）给出「一瞬在画布上有多短」。
- **下游**：交给口袋（80）——烟花灭了，痕进兜里；交给礼物（79）——自己也是一次性的，跟烟花同构。
- **与黑暗（76）**：烟花是黑暗里少数亮得起来的时刻，所以它才被记住。
- **与灾难（75）**：灾难是「同一没了」，烟花是「同一只来过一下」——后者不算消失。
