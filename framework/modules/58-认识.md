# 58 · 认识：知识的获取与应用

> 一句话：认识是把知识拿进来又用出去的那一段——从「读到、听到」变成「我的」，再落到眼前这件事上。

## 一、它是什么

认识有两个动作，缺一个就不完整：

- **获取**：把外部的东西变成自己的——不是存下来，是理解、验证、和旧知识连上。
- **应用**：把知道的用到眼前的对象上——认出该用哪一条、用几分、什么时候停。

只获取不应用，是知识仓库：存了一屋子，一件没用过。只应用不获取，是瞎干：凭手感和旧习惯，遇到新情况就露底。

它和 28 知识的分工：28 管「有没有、存不存得住」，58 管「怎么拿进来、怎么用出去」。知识是库存，认识是进出。

## 二、结构

五步，一条链：

1. **信息**：先有可读的材料（27 信息）。
2. **取**：读懂、验证出处、和已有的知识连上——连不上，它就只是听过。
3. **存**：变成能调用的形态（28 知识），能说得出、能用得上。
4. **用**：找到对应的对象，确定用哪一条、用到什么程度、边界在哪。
5. **反馈**：用对了没有？用错的那次，改的是知识还是用法。

## 三、怎么动

- **获取靠连接**：新东西和旧知识连上才存得住；连不上的，过两天就散。
- **应用靠对应**：能不能在眼前这件事上指出「用的就是这一条」——指不出，就是没用上，只是想起来过。
- **用错不一定知道**：用错了当场没有信号，只有违和感（R21）；要靠事后对结果，才知道用法错了。
- **不用的会钝**：知识放着不动会钝，用得越少越调不出来。
- **应用会反过来改知识**：用出来的经验修正库存——原来那条不灵，换成一条更细的。
- **获取与应用互为条件**：用得越多，越知道该补什么；补得越多，用得越准。

## 四、判据

获取：

1. 说得出它从哪来、怎么验证的吗？
2. 它和我已经知道的哪一条连上了？

应用：

3. 说得出它用在这件事的哪一处吗？
4. 用完之后对过结果吗——用对了，还是用错了？
5. 用错的那次，改的是知识本身，还是用法？

## 五、边界

**不管**：信息本身（27）、知识本身（28）、学习（39 管把本事装成自己的）、工作（38 管替人做事）。

三种常见错法：

- **把读过当认识**：看过、听过、收藏过，就当自己知道了。获取没走完，应用无从谈起。
- **把知识当应用**：说得出那条道理，说不出用在哪一处。知识是库存，不是使用记录。
- **用错不改库存**：同一处用错好几次，还是照旧用——那不是认识，是惯性。

## 六、接口

- **与 27 信息**：信息是原料，认识是加工和使用。
- **与 28 知识**：知识是库存，认识是进出；库存不动，认识就钝。
- **与 39 学习**：学习管「装成自己的」，认识管「用出去」；装好了不算，用通了才算。
- **与 10 记忆**：认识要翻得出旧知识，靠的是记忆的取回。
- **与 32 真值**：用之前先问这条知识在什么范围里真；范围不对，用法就错。
- **与 38 工作**：工作是替人做，认识是替自己判；两者共用一条链，但标准不同。
- **与 57 体验**：用过一次的体验会加固认识；没用过的知识，只有说明，没有手感。

## 七、自查

1. 这一步是获取，还是应用？我是不是把其中一个当成了全部？
2. 获取的东西，我验证过出处吗？
3. 应用的那条，我说得出用在哪一处吗？
4. 用完之后，我回头对过结果吗？
