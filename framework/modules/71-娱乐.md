# 71 · 娱乐

> 一句话：不为产出而做的事；读书、看报、刷视频、听音乐、游戏都算。

## 一、它是什么

娱乐是**自愿投入、不为产出**的活动。它看过程，不看结果——哪怕最后什么都没得到，这段也不算白过。

它有兩種長相：

- **有框的**：游戏、竞技、解谜。有规则、有输赢、有对手。
- **无框的**：读书、看报、刷视频、听音乐、看剧、闲聊。没有输赢，只有「看进去 / 听进去」。

两种是同一个东西的两个长相，分界不在形式，在**做它图什么**。同一件事可以两属：打游戏是娱乐，打比赛是工作；读书是娱乐，读书出报告是工作。

本质一句话：**娱乐是过程本身值钱；一旦过程只为了换别的，就归到别处去了。**

## 二、结构

四样，缺一样就变味：

1. **自愿**：能停。停不下来的时候，已经不是娱乐了。
2. **投入**：注意力真在里面。一边刷一边发愣的，是耗着，不是玩着。
3. **不图产出**：可以有产出，但产出不是做它的理由。
4. **代价小**：失败、走神、半途而废都不损失真实的饭。

第三样最容易被忽略：拿「有没有学到东西」给娱乐打分，它立刻变成工作。

## 三、怎么动

娱乐会变质，三条路：

- **被考核**：加了 KPI、打卡、年度报告，娱乐变工作。
- **被加注**：拿真钱真前途去赌，娱乐变赌局。
- **被投喂**：算法一直喂下一个，人停不下来。这时候不是你在娱乐，是它在娱乐你。

也会反向长回来：把一件累事拆成能随时停的小段，加一点自己选的乐子，就带回娱乐的样子。

一条经验：**娱乐的边界不在做什么，在能不能随时停。** 能停的是消遣，停不下的是瘾。

## 四、判据

1. **我能停吗？** 停不下，先别叫它娱乐。
2. **我是为了过程，还是为了结果？** 为了结果，它就是工作或投资。
3. **注意力真在里面吗？** 只是放着声音、滑着页面的，是在耗时间。
4. **谁在选下一个？** 自己选的，是娱乐；被推荐喂的，是投喂。
5. **停了会不会难受？** 难受是瘾，不是享受。

## 五、边界

**不管**：赌博（真赌注，归风险与法律）、成瘾（归医学）、职业竞技与内容生产（那是工作）。

三种常见错法：

- **把娱乐当罪。** 一闲就看不起自己，于是玩得心不在焉，事也没做好。
- **把娱乐当正事。** 玩也考核，玩完还复盘，两头不落好。
- **把刷当娱乐。** 刷是被喂，选才是玩。两者的差别就在「下一个是谁挑的」。

## 六、接口

- **上游**：闲暇（72）给出能玩的时间；自主（12）给出「想玩什么」的起念。
- **下游**：交给关系（37）——一起玩是黏合剂；交给体验（57）——玩过的会留下痕迹。
- **与工作（38）**：对偶。工作看产出，娱乐看过程；判据混用，两边都坏。
- **与旅行（69）**：旅行要离家，娱乐不用；都能「不在日常」，但一个换地方，一个换注意力。
- **与闲暇（72）**：闲暇是空出来的底，娱乐是填进去的东西；底没了，填什么都是加班。

## 七、自查

1. 这一把，我是自愿的吗？
2. 我图的是过程还是结果？
3. 谁在选下一个——我，还是推荐？
4. 停下会不会难受？
5. 我是不是在拿「有没有收获」给玩打分？
