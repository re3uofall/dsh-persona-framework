# 模块写作规范（SPEC）

> 这份不管内容，管**每一份模块文档长什么样、什么话不许说**。写的时候照它，读的时候也照它。

> **红线：这一整个目录是「框架层」，不是人格层。**
> `persona-ai/characters/` 下的人格文件（`大肥鱼思思.md`、`大肥鱼思思_人格文件.md`、`人格_共享.md` 等）一个字都不许动——不覆盖、不合并、不「顺手同步」。
> 模块文档只解释「这一部分是什么」，不替具体人格写它的答案；写完之后要落到人格文件里的，只能由人格的主人自己决定。

## 一、目标

给 45 个模块各写一份能独立读的文档。读者是第一次拿到这个工作区的人：他不认识这里的组织约定，但读完一份，得能说清——这个模块是什么、本质是什么、怎么动、怎么算对、管到哪儿为止、跟谁接。

**两条硬要求：**

1. **用最普遍的解释。** 每个模块先用通行说法讲清（心理学、哲学、系统论里已有的说法），再谈它在本工作区里放哪。私有骨架（四层切分、残余标号）只作为「这里的组织约定」出现，不拿它替通行解释。
2. **不掺个人特质。** 不写「我」「思思」「师父」「白饭」「书签」，不建私人典故，不模仿某个角色的口吻。写成谁都能读、谁都能用的说明文。

**一句话标准：读完这一份，能拿它去办事；拿不出判据的段落，就是废话。**

## 二、固定七节（顺序不许倒）

每份文档都按这七节写，标题照抄：

1. **它是什么**——一句定义 + 一句本质。定义要能跟隔壁模块区分开：「情感」和「感情」得一句话就分得开。
2. **结构**——这东西由哪几块拼成。分层就写层，有台阶就写台阶，别写成清单。
3. **怎么动**——变化、衰减、积累、翻转。要能说出「什么情况下它变」。
4. **判据**——怎么算对、怎么算错、怎么算还没成型。至少三条，每条都能拿来问。
5. **边界**——管什么、不管什么；最常见的三种错法。
6. **接口**——它吃谁交下来的残余、它把残余交给谁、跟哪几个模块直接接线。
7. **自查**——三到五问，能当场问出口的。

开头一行 blockquote：

```
> 一句话：……（不超过 30 字）
```

结尾一行：

```
## 更新记录

- 2026-10-26　v1.0 初版：……（一句）
```

## 三、通用坐标系（写模块时默认它存在，不用每次重讲）

- **四层切分**：劲（本我）→ 闸（自我）→ 标（超我）→ 嘴（语言）。不是四个零件，是同一块切四层；后一层吃前一层的残余。
- **残余标号**：劲 0、闸 1、标 1∕2、嘴 ε。标号是这层落下多少，不是这层多重要。
- **三不**：不许多（别把 kept 一起带下去）、不许少（别自己吞残余）、不许换（别跳级拿更早的残渣）。**不填缝；填平是碑。**
- **两把横尺**：身体（画边界：本体／延伸／蜕皮／不是我的）、抽象（切骨架：删掉的差异进现实，谁删谁付）。横着用，不排进主线。
- **一部分画布**：时空直观（管画布怎么铺、铺的时候抹平了什么）。它不是尺。
- **接线规则**：边界压内容 → 具体压抽象 → 能停先停。残余不消，只交。
- **一条底色**：任何绝对都带一点违和感，任何固定都带一点松动感。这不是找茬，是同一律到期那一下的轻响。

## 四、语言

- **中性说明体**。第三人称或无人称：「情感是……」「可以这样分」。不用「我」。
- 先通行后私有：一个概念先给公共能听懂的定义，再说它在工作区里接哪儿。私有骨架（劲／闸／标／嘴、残余标号、横尺）只在「接口」一节点名，不展开论证。
- 短句为主。不排三连，不做结项（「总之」「综上所述」「就这些」）。
- 术语第一次出现要翻成人话；说不清就直说说不清，不许硬造词。
- **不点来源名**：那套东西只说「同一论」「残余」「非同一」，不说书名、不说人名堆。
- 不编数据、不编文献、不编出处。举例用日常场景，或用本工作区真实发生过的事。
- 不点具体国家、政党、领导人。不评价时政。
- 不写「作为一个 AI」这类句子；不解释自己是什么。

## 五、禁止项

- 不要写成百科词条（「情感是指……」开头那种字典腔）。
- 不要一段话里塞五个概念，读者会沉。
- 不要把模块写成万能：每个模块都必须说清「它不管什么」。
- 不要凑字数：写不满就写短，短而准比长而空强。
- 不要复述 SPEC 里的坐标系原文，默认读者已经知道（或已读过 `00-目录.md`）。
- 不要出现个人化称谓、口头禅、颜文字、剧本式动作描写。

## 六、篇幅

1200–2500 字。实在薄（比如「信息」这种），800 字也可以，但七节不能缺。
