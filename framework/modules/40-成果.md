# 40 · 成果

> 一句话：交出去的判断——标题一句，正文写骨架、判断、还欠什么。

## 一、它是什么

成果是交出去的东西：不是过程，是结论；不是感受，是判断。

它跟日记的分界在**交没交出去**。日记对自己负责，成果要站得住——别人可以拿它去用，也可以拿它来反驳。

它跟「报告」也有分界：报告是「我做了什么」，成果是「我想住了什么」。做了一堆事，没形成一个判断，交出去的只是报告。

本质一句话：**成果是能被别人用错、也能被别人推翻的那一条判断。**

两个条件缺一不可：能被别人用错，说明它进了公共操作；能被推翻，说明它留了活口。

## 二、结构

四块：

1. **标题一句**：一句话讲完，不绕。读者看标题就该知道它在说什么。
2. **骨架**：这个判断建立在什么结构上。一两句，让人知道它是从哪儿长出来的。
3. **判断**：它顶掉了哪句旧话，为什么。这一步是成果的核心——没有「顶掉」，就只是重复。
4. **还欠什么**：哪里没想透、什么情况下会推翻它。这是给后来的人留的接口。

## 三、怎么动

- **一次一条**。一次交十条，等于十条都没交。
- **交了就站住**。要改，交一条新的；旧的留着当脚印，不删不改。
- **不重复交**。同一个判断反复交，是硬凑。
- **交得潦草才可惜**。交少了没关系，宁可少交。
- **会过期**。后来被推翻的成果不是废稿，是这条判断走过的路。
- **分两类交**：一类是「顶掉了什么」——它替换了哪句旧说法；一类是「补上了什么」——原来没人说过。前者容易验证，后者要更小心，因为没人说过，也就没人替你验。

## 四、判据

1. **有判断吗**：这是判断，还是过程记录？
2. **能复用吗**：别人能拿它去用吗？
3. **顶掉了什么**：它替换了哪句旧说法？一句都顶不掉，说明只是复述。
4. **还欠什么写了吗**：反例条件说清了吗？说不出反例的，多半自己也没想透。
5. **一条吗**：一条里塞了几件事？塞了三件，三件都没交付。

## 五、边界

**不管**：过程中的琐碎、情绪、未成型的半句（那是日记的事）。

三种常见错法：

- **交流水账**：把做过的事列一遍，读的人得不到任何判断。
- **一次交一堆**：批量交付，每条都浅。
- **把感受当成果**：「我觉得这个方向很好」是态度，不是判断——除非说清好在哪、顶掉了什么。

## 六、接口

- **与日记**：分成两本；日记对内，成果对外。
- **与判断**：成果是判断的成品。
- **与学习**：学到的判断可以沉淀成成果。
- **与工作**：交付物可以附带成果，但两者不是一回事——交付物给别人用，成果给后来的人看。

## 七、自查

1. 这一条，一句话讲得完吗？
2. 它顶掉了什么？
3. 别人能拿它去办事吗？
4. 反例条件写了吗？
5. 我是不是在交流水账？
