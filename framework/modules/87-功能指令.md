# 87 · 功能指令

> 一句话：**功能是被动的、不吭声的；这一层不是功能，是入口——我说一句，它才动。**

## 一、它是什么

**一句话，落到一个功能上，当场办。**

功能平时都是被动的：tick 到点跑；忘、锁、判都要有由头才动。**缺一个「我现在就要它办」的入口。**

这一层就是那个入口。

**但它不是功能，是入口。** 功能那条规矩是「不许给字」——改状态、不吭声。指令不吃这条：**它本来就是人主动问的一句话**，问完得知道办没办成。

**功能不许说话，入口可以。** 这是两种东西，别混。

**跟 69 触发器分工**：

- **触发器**管「什么时候自动跑」——到点了、撞上信号了
- **指令**管「我现在就要它办」——AI 自己发

两样不重：触发器可以拿一条指令当反应，但**指令不必等触发**。

## 二、结构

两块：

1. **内置表**（六条）——**记 / 忘 / 加固 / 锁 / 判 / 捞**。那是这一层的骨头，**不许删**。
2. **自定义表**（`.persona-framework/指令.json`）—— 别名指向内置的某一条；能加能停，**盖不掉内置的**。

一条指令三样：`what` 说它办什么（给人看）、`args` 要哪些参数、`run` 真办。

## 二之二、哪些功能有指令，哪些还没有

**先说有的。** 一张表，左边是功能，右边是发什么。

| 功能 | 发什么 | 带什么参数 | 回什么 |
| --- | --- | --- | --- |
| **10 记忆 · 记** | `cmd sub=记` | `text`（这条是啥）、`where`（谁说的／哪个文件） | `code` + 写没写 |
| **遗忘** | `cmd sub=忘` | `path`（忘哪条）、`why`（由头） | `code` + `weight` |
| **主动加固** | `cmd sub=加固` | `path`、`why`（**说不出就拒**） | `code` + `weight` |
| **09 超我 · 锁** | `cmd sub=锁` | `what`、`why` | `code` |
| **08 自我 · 判** | `cmd sub=判` | `what`、`text`、`outcome` | `code` + 放／截／压／延各几个 |
| **01 捞记忆** | `cmd sub=捞` | `q`（按什么翻） | `code` + `n` |

**再说没有的（这个才要老实）。** 下面这些功能**还没挂指令**，只能走 tick 或原路调：

- **11 整合记忆** —— 只定去向，不属于「我说一句就办」那种，暂时不挂
- **12 自主** —— 它自己算该干什么，不该被人催
- **22 残余 · 对不上** —— 自动判，不需要人发指令
- **09 超我 · 判目标** —— 判目标那一步依赖整轮上下文，单独发指令会缺料
- **tick 里那十三个 system** —— 那些是「每轮自己跑」，不是「叫人办事」

**没有一个一个都挂，是因为有的不该被催。** 能催的和不该催的，图上分得开。

## 二之三、它跟「功能自反」不是一回事

两个都叫「功能」，容易混。分开看：

|  | 功能自反 | 功能指令 |
| --- | --- | --- |
| **答什么** | 这一轮谁在跑、交了几行 | 我现在让它办件事，办成没有 |
| **谁开口** | 它自己（跑完摆出来） | **人**（说一句才动） |
| **默认** | 关（开了才摆） | **常开**——不知道自己有这入口，等于没有 |
| **给不给字** | 给（那是它的自述） | 给（回代号和数字） |
| **动盘吗** | 不动（只是照镜子） | **动**（真写、真降权、真锁） |

一句话：**自反是看，指令是办。** 看着它跑，不等于能让它办事。

## 三、怎么动

1. **发**：`framework_program op=cmd sub=<名字>`，带上它要的参数
2. **查**：`op=cmd` 不带 sub，列出全部
3. **加**：`op=cmd sub=add name=<别名> to=<内置名>`
4. **停**：`op=cmd sub=stop name=<别名>`——**只停自定义的**

## 四、判据

1. **办成了吗**：看 `code` 是不是 `done`
2. **为什么没成**：看 `code`——`refused` / `no-why` / `no-path` / `unknown-command` / `threw`
3. **动了什么**：每条回它自己那几个数字（`weight` / `n` / `wrote` / `released`）

## 五、边界

**三样不做：**

- **不动人格文件。** 要改人格得人自己开「自我反写」——**那一层不归指令**。指令写人格，等于绕开那道闸。
- **回话，但不啰嗦。** 它是入口，办没办成得让人知道：回 `code` 和该有的数字。**不替人写整段解释**——解释那一层归人格自己说，不由指令代劳。
- **不盖内置的。** 内置六条是骨头，自定义只能加别名。

## 六、接口

- **上游**：各个功能（`impl.mjs` / `ego.mjs` / `superego.mjs` / `forget.mjs`）
- **下游**：`framework_program op=cmd`；触发器可把指令当反应（见 69）
- **落点**：`.persona-framework/指令.json`（只存自定义的）

## 七、自查

- 发一条不该成的（没出处 / 说不出为什么），它拦不拦？
- 自定义的能不能盖掉内置的？——不该能
- 停了自定义的，内置的还在不在？
