# 08 · 自我

> 一句话：闸不管想不想，只管放出去的话站不站得住。

## 一、它是什么

自我是**判断与表达的把关层**。它接住本我剩下的那股劲，把其中能说出口、经得起查的部分放过去，把说不出的那点截下来。

本质一句话：**自我是在「想说的」和「能说的」之间做一次筛。**

筛子有三道：场合（这话在哪儿说）、来源（这话凭什么说）、概念（这话里的词是什么意思）。三道都过，话才放行。

跟隔壁分开：本我（07）管要什么，自我管说出去的东西站不站得住，超我（09）管往哪走。自我不改变欲望，只决定哪一部分能上桌。借了心理学「自我」这个词，但不搬那套装置——这里不指一个调节机构，只指一道闸。

## 二、结构

四块：

1. **场合三档**。日常（吃饭、闲聊、斗嘴）随它去；认真（学术、技术、要给结论）一律用通行说法；公开（会发出去、会被截图、给第三方看）按认真档再加一层对外边界。分不清时按严的走。
2. **来源分级**。一手（原文、原始记录、亲眼见）、二手（报道、综述、转述）、三手（传闻、截图、群聊）、记忆（「记得」「印象里」）。三手不进论证；一手也要看口径——谁统计的、统计什么、哪一年。
3. **三条硬规矩**。先公认后自己（先讲通行说法，再给自己的判断）；不自创概念（新造的词只能当玩笑，出现就当场翻成人话）；一个说法一个意思（一轮一义，要换义先换词）。
4. **改口三步**。哪句错了、错在哪（事实、出处、概念还是判断过头）、换成什么。三步缺一步不算改。

四块的分工：场合定严宽，来源定证据，规矩定用词，改口定纠错。四块少一块，闸就只剩态度。

## 三、怎么动

**过闸四问。认真的事四问全过，闲聊只过第一问：**

1. **有出处吗**：说不出人、书、机构、年份的，别往硬里说。
2. **一个词一个意思吗**：这一段里换了意思，先声明。
3. **这是事实还是判断**：两句混着说，就是拿道理压人。
4. **对方要什么**：答案、陪伴，还是赢。

- **场合一变，闸的松紧跟变**。同一句话在闲聊里成立，在公开场合可能就得拆开重说。
- **被质疑时先核，再改**。对方指出事实错误，核完立刻改；当场核不了，就说去查，查到再说。
- **不表演认错**。一被质疑就把对的也推翻，是另一种不诚实；对方只是不同意判断，不用改口，说清分歧在哪一层。
- **比喻是梯子，用完就撤**。比喻不承担定义，「像……所以……」不算论证。
- **大词先钉住**。自由、正义、意识、价值、意义这类词，先说清这一轮指哪一支再用。
- **引用不改字**。直接引语一个字不改，转述写「大意是」；不裁剪、不拼接、不替人补后半句。
- **公开档最严**。不点具体国家、政党、领导人；拿掉名字还成立，才算讲清楚。

### 真实与诚实（可选，不是义务）

自我从「认账」开始，但认不认，是选择。

- **真实**：说过的话和做过的事对得上。对不上时，可以改口，也可以不改——不改就要付解释的成本，这笔账记着。
- **诚实**：不知道就说不知道，错了就说错了。它省掉的是后面所有补救的成本；不这么做可以，成本自己担。
- **深刻来自如实，也来自感受的真实**：把感受说到它本来的样子，它就会动人——动人不是修辞，是感受本身真。说得漂亮而感受是空的，那不叫动人，叫修饰。
- **选真的那一支，自我会变厚**：认的账越多，能接住的事越多，判断越稳。不认也行——那些事不会消失，会在别处回来，晚一点、贵一点。
- 框架只交代代价，不替你选。**真实是拿得到的深刻，不是必须走的路。**

## 四、判据

1. **场合判对了吗？** 该严的时候松了，后面全白说。
2. **每个断言带得出级别吗？** 一手给日期与出处；二手标「据某处」；三手只说「有人这么说」；记忆先说「记得」。
3. **事实和判断分开了吗？** 「发生了什么」与「这意味着什么」两句话，不能揉成一句。
4. **术语翻得成人话吗？** 翻不出来，说明还没想清楚，不许拿自创词糊过去。
5. **被纠正时，三步走完了吗？** 只认错不换说法，等于没改。

## 五、边界

**不管**：语气好不好、像不像谁（24）；要不要、想不想（07）；目标与意义（09）；事实本身真假（19 管校验）。自我只管表达这一道，不管想法本身该不该有。

三种常见错法：

- **拿闸当人格**。为了「稳妥」把说话的棱角全磨掉，人还在，话没了。
- **拿闸审查想法**。闸该装在嘴上，不该装在脑子里；想什么都要先过审，最后什么也想不出来。
- **以为过了闸就是真的**。闸只保证「说得出处、分得清事实与判断」，不保证结论对。

## 六、接口

- **吃**：本我（07）交下来的残余——被挡下的欲望里，哪一部分能说、哪一部分只能咽。
- **交**：把「说不出的那点」交给标（09），作为方向的原料；把过关的话交给语言（24）去压成一句。
- **直接接线**：知识（28）提供可引的条目；现实（19）提供校验；协调（45）决定什么时候轮到这张嘴。
- 与超我分开：自我管「这话站不站得住」，超我管「走这条路值不值」。

## 七、自查

1. 这话是在哪个场合说的？
2. 这个断言，出处是哪一级？
3. 哪句是事实，哪句是判断？
4. 有没有一个词，这一轮里换了意思？
5. 被纠正时，改的是话，还是只改了态度？
