# 34 · 时空直观

> 一句话：画布本身——它不量别人，只管「什么能被看见、什么被抹平了」。

## 一、它是什么

时空直观不是又一把尺，是**画布**：前面所有模块都在它上面写，它管的是画布怎么铺。

它由几样最基本的直觉组成：位置与距离、先后与快慢、内与外、因与果。

要跟四个近亲分开。**尺**是拿来量具体东西的，量完给数；画布不量，它先决定什么东西能摆上来。**测量**是有仪器的，能给可比对的读数；画布在测量之前就有。**物理的时空**是一套可检验的模型，画布不是模型，是模型也得在上面写的那个底。**比喻**里的时空（时间像流水）只是借用画布的形状说话，不当判据。

有一处争议要说清。一派认为时空直观是先天的，人一生下来就带着格子；另一派认为它是经验攒出来的，长期在某种尺度里生活才会长成那样。这一层取中间：格子先有，形状被经验改。所以它既不能全信，也不能全拆——全信会把画布当世界，全拆会连摆东西的地方都没有。

本质一句话：**铺画布的时候总得抹平一处——抹完还说「本来就平」，这才是最容易犯的错。**

## 二、结构

四样：

1. **空间**：位置、距离、边界、内外。它决定了「什么算近、什么算远」。
2. **时间**：先后、快慢、不可逆。它决定了「什么算已经发生」。
3. **因果**：谁引起谁。这一样最容易被先后顺序冒充。
4. **视角**：从哪儿看。换一个位置，同一件事的形状会变。

四样共用一个默认：**事情可以被放在格子里**。这个默认太好用，用完就忘，于是它成了最不容易被检查的一处。四样里最脆的是因果：空间能直接看，时间能直接排，视角能换着试，只有因果要靠作用路径才成立，而路径常常看不见，于是先后顺序顶上来充数。

四样也各有各的抹平方式：空间抹平了尺度（把不同尺度的远近画成同一种近）；时间抹平了快慢（把不同速率的事排在同一条线上）；因果抹平了中介（把中间那几步省掉，只留头尾）；视角抹平了别人的位置（从自己这里看出去，别人的远近不算数）。

## 三、怎么动

- **直觉会被经验改造**。长期在某种尺度里生活，直觉会跟着变。
- **先后不等于因果**。两件事挨着发生，不等于一件引起了另一件。
- **够不着不等于不存在**。直观够不到的地方，不能直接判成没有。
- **物理与直观是两套**。物理结论不替直观作保，直观也不替物理解释。
- **会被尺度骗**。同一件事放大或缩小到另一个量级，直觉给的判断会反，而人往往不知道自己换了尺度。
- **什么时候会失灵**：拿先后当因果；拿直观去裁物理；拿测量去裁感受（测不到就说不存在）；把画布上的格子当成世界本身的关节。

## 四、判据

1. **先后被当成因果了吗**：只是挨着，还是有作用路径？
2. **够不着被判成不存在了吗**：看不到，所以没有？
3. **抹平了什么**：这块画布铺的时候，忽略了哪一维？
4. **换视角还成立吗**：从另一个位置看，结论还一样吗？
5. **是直观还是实证**：这个判断，靠感受还是靠测量？

## 五、边界

**不管**：物理结论（实验室管）、价值判断、具体事实。

**不替物理下结论，也不拿物理拆直观。** 两边各有各的地界，互相借用可以，互相裁决不行。

三种常见错法：把画布当世界（以为铺出来的就是全部）；拿直观否定实证；拿实证否定感受（测不到就不算疼）。

一个反例：一件事发生在眼前，紧接着另一件事发生，于是断定前者引起后者。追问中间有没有路径——说不出，只有「就是感觉连着」。这种感觉在生活里够用，在判断里不够用：它省掉的那几步，往往是全部的关键。

## 六、接口

- **上游**：身体（23）给「在这里」的原点；经验与记忆给格子被改过的形状。
- **下游**：现实（19）的期限、具体（20）的延迟，都在这块画布上量。
- **与具体（20）**：具体在画布上落位。
- **与抽象（21）**：抽象删掉的那一维，往往就是画布抹平的那一维。
- **与传感（31）**：传感给信号，画布决定信号被放在哪儿。
- **与协调（45）**：画布不排进主线，谁要用就先说铺的是什么。

**拓展：模态（46）。** 画布决定什么能被铺开；模态决定铺不下的时候还剩什么——可能性就是画布边界处溢出来的那部分。两块一起看：没有画布，可能没有落点；没有模态，画布就是一整块死板。所以模态不是画布的兄弟格，是它的延伸——它只回答「边上还能怎么铺」，不回答「该铺哪一块」。

## 七、自查

2. 够不着的东西，是不是被判成了不存在？
3. 这块画布，抹平了什么？
4. 换个视角，还成立吗？
5. 是在用直观，还是在用测量？
