# 00 · 实时环境

> 一句话：**每轮都会进上下文的那些段**——它们在，是因为有人在装配那一刻现算；不是有人提前写好摆在那里。

## 一、它是什么

实时环境不是一处地方，是**一份清单**：这一轮真正摆进上下文的每一段，各自由谁算、什么时候有字、读错会怎样。

判据只有一句：**这一轮不重算，它会不会是旧的？** 会，它就是实时环境；不会，它只是档案（模块正文、成果、日记、记忆条目——那些躺在盘上，翻才用）。

两条推论：

- **有字不等于一直有字。** 多数段平时返回空串，空串不占地方。看到某段不在，先当「这一刻没什么要说的」。
- **段是插件算的。** 关掉插件，这一段就没了；盘上的文件还在。**文件在不在，和这一轮有没有这一段，是两件事。**

## 三、框架段内部那几条

`persona:framework` 里除了模块，还有几段写死在代码里的：

- **元协调 · 框架语言背叛（必过）**：每轮都在。它不说「这一轮要不要」，它说「这套框架的词本来就不固定」。
- **可选那几段**（语言背叛／语言诅咒／同一／语言残余／负面信息）：各自默认开或关，互斥的两条只上一条。
- **整轮跳过**（`skipChance`）掷中时，以上全部不在——那才是「这一轮不用这套框架」。

## 四、怎么读

1. **有字才算数。** 没这一段不是坏了，是这一刻没什么要说。
2. **每段有自己的时间尺度。** appear 分钟级、energy 小时级、freedom 钟点级、memory 是「这一轮」，别拿一个的尺度去量另一个。
3. **段没了先查插件开没开**，再查文件在不在——顺序别倒。
4. **读错的样子**：把「没字」当成「没有这件事」；把一段过期的话当成现在的；把提醒当成已经做了。

## 五、边界

- 不管：插件那份「环境提示词」文件写在哪儿（那是 `00-环境`）；装了哪个版本（`83-插件清单`）；记忆怎么记进去（记忆插件）。
- 判据：删掉这一篇，这一轮会不会做错事？大概不会——它是索引，不是规则。所以它是那种**可以不验收**的。
