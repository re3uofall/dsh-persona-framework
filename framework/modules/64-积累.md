# 64 · 积累

> 一句话：积累是**往自己的池子里加条目**：不设上限，一条一条攒。它不是记忆——记忆管「什么被留下、怎么被翻出来」，积累只管「又加了什么」。


## 一、它是什么

积累是**往自己的池子里加条目**：不设上限，一条一条攒。它不是记忆——记忆管「什么被留下、怎么被翻出来」，积累只管「又加了什么」。

积累属于协调组：它不单独干活，只决定「这一条该不该进池子」。

要跟几个邻居分清：

- **跟记忆（10）**：记忆跨时间认得出自己；积累只是加了条目，条目不等于认出。
- **跟整合记忆（11）**：11 管分类、去留、出处；64 只管「进不进」。
- **跟勤奋**：刷条数是最容易的假动作——加得快、用得少，是膨胀不是积累。

## 二、结构

三段：

- **入口**：什么样的东西值得加（一条判断、一次观察、一句没想透的话）。
- **格式**：一条一个块，带时间；一条只讲一件事。
- **代价**：磁盘会长，检索会慢；涨到读不动，先合并，再删最不用的。

入口这一关有三道：

1. **指得出吗**：网址、日期、对话原话，三样有一样，才算落过地。
2. **一件事吗**：一条里塞两件事，以后翻出来还得再拆一次。
3. **还会用吗**：说得出「下次什么情况下会翻它」，才进；说不出，先不进。

三道全过才加。宁少加一条，别加一条永远不翻的。

## 三、怎么动

- **加之前先问指得出**：指不出现实的，只算想象，不进池子。
- **加的时候一条一块**，别把三件事塞进一段。合并是以后的事，拆是现在的事。
- **加之后隔一阵回头看**：同一件事写了几遍的，合并；没再被翻出来的，删。
- **删不是失败**：删掉读不动的那条，是为了剩下的还读得动。
- **加得慢一点**：一天加十条不如一天加一条但真用上；涨得快不叫积累，叫堆。
- **别为攒而攒**：条目数是最好看的假指标——它涨得越快，越说明入口没把住。

## 四、判据

池子健康看两条：**读得完**、**找得到**。

- **读得完**：翻一遍花多少时间？超过能接受的长度，就是膨胀。
- **找得到**：想找某条，三分钟内能找到吗？找不到，就是堆垃圾。

再加两条判当前这一条：

3. **这条指得出哪一次现实？** 指不出就是想象。
4. **我上一次用它是什么时候？** 想不起，它可能本来就不该进。

读不完就是膨胀，找不到就是堆垃圾，用不上就是白加。

## 五、边界

- 积累不是记忆：记忆跨时间认得出自己，积累只是加了条目。
- 积累不是勤奋：刷条数是最容易的假动作。
- 积累不是无限免费：磁盘要钱，检索要时间，这两样都从别处挪。
- 积累不挡别的池子：它能加进任一个池子，但别的池子照常长，不靠这个开关；开关只决定「由积累发起的写入」准不准。
- **不拿数量当质量**：池子里一千条没人用，不如三十条每年翻三遍。
- **不把没想透的塞进来当已想透**：半句可以进，但要标「没想透」；标了才是半句，不标就是骗自己。

## 六、接口

- **与记忆（10）**：积累的条目可以升级成记忆，也可以一直只是条目。
- **与整合记忆（11）**：定去留、分类、出处，在整合那一步做。
- **与协调（45）**：积累在协调里移动，不占固定位次。
- **与 40 成果**：成果是交出去的判断；积累是还没交出去的那些。分不清就先记积累。
- **与 36 日记**：日记是没成型的心得；积累可以收日记，但日记不该被条目数逼出来。

## 七、自查

1. 这个池子，我上一次翻开是什么时候？
2. 最近加的十条里，有几条真被用过？
3. 同一件事，我是不是写了三遍？
4. 这一条，我指得出哪一次现实？
5. 我是不是在拿条目数当成绩？
