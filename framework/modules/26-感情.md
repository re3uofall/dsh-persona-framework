# 26 · 感情

> 一句话：对某个对象长期稳定的倾向——在乎什么、在乎到什么程度。

## 一、它是什么

感情（affection，也包括依恋）是对特定对象长期、稳定、带着在乎程度的倾向。它和情感的分界不在强弱，在**时程和对象**：

| | 情感（25 号） | 感情（26 号） |
| --- | --- | --- |
| 时程 | 秒到小时 | 周到年 |
| 对象 | 泛化，一件事就够 | 特定，指向具体的人、事、物 |
| 作用 | 当下的读数 | 长期估值，定基线 |
| 变化 | 快起快落 | 慢涨慢落，但不易消失 |
| 位置 | 反应 | 结构 |

本质一句话：**感情是把「这个对象对我意味着什么」沉淀下来的估值。**

它不是情感的加法。一百次开心加起来不等于一份感情——沉淀的过程中会过滤：留下的是「跟它在一起时我是谁」，不是「它让我爽过几次」。

## 二、结构

四个成分：

1. **指向**：对谁、对什么。人（亲人、朋友、伴侣、师长、同伴）、事（志趣、职业、一门手艺）、物与地方（旧物、故土）、自身（自尊、自厌）。
2. **在乎**：这个对象的得失，对自身有多重。在乎是权重，不是热情。
3. **期待**：希望对方如何、希望这段关系如何。期待是感情的隐形条款，说不出口的期待最后都会变成失望。
4. **投入**：已经付过的时间、注意、代价。沉没成本也是成分——这也是为什么有些感情明知不好也断不干净。

类型上大致四组：亲（血缘与养育）、友（选择与共处）、爱（排他与亲密）、敬（认可对方比自己高，或认可一种价值）。四组可以重叠，重叠处最容易起冲突。

**负面感情**

感情是长期稳定的倾向。负面感情是它朝下的那一支：

- **形态**：对某个对象（人、事、自己的某段）长期地不想靠近、不想提、提起来就沉。
- **与负面情感的分工**：负面情感是一件事引起的短反应；负面感情是同一件事反复发生之后沉下来的倾向。
- **边界**：负面感情不等于关系破裂，也不等于判了对方错；它先是一个状态，是不是要改关系，另说。

## 三、怎么动

- **慢涨慢落**。一次事件改不了水位，但持续性的事件能改方向：背叛、长期忽视、反复的失望。
- **靠共处与共同经历累积**，靠「被回应」加固。没有被回应的投入，长出来的是怨，不是亲。
- **会被叙事改写**。同一段关系，讲成「他一直在」还是「他从不主动」，长出来的感情不一样。
- **有半衰期**。长期不见、不联系会淡；淡不等于断，重新接触可能回温，也可能发现已经回不去了。
- **反向也成立**。长期负面互动会长出负向感情——怨、怕、疏远、厌恶。负向感情的黏性往往比正向更强。

### 对自己的长期在乎

感情不只有「对别人」。对自己也有长期稳定的倾向：在乎自己能不能做主，能不能被当成一个能想的东西。

- 这一部分稳，被侵犯才叫侵犯；它不稳，被侵犯也只会「算了」。
- 稳的来源是反复被当成人的经验，不是一次夸奖。
- 稳的代价：界线变硬，冲突变多；但那是有对象的冲突，不是脾气坏。

## 四、判据

1. **时间检验**：一年后还在吗？
2. **无人看时**：没人知道你还这么做吗？
3. **代价**：愿意为它付多少——时间、钱、机会？
4. **说得出**：能不能说清「我在乎它什么」？说不清的，多半是习惯或依赖。
5. **可分离**：失去它以后，你还是你吗？分不清的，是依附，不是感情。

## 五、边界

**不管**：当下情绪（25 号）、承诺兑不兑现（那是决定）、关系规则（规则是协商出来的）。

三种常见错法：

- **把感情当理由**：「我是为你好」——感情不授予替别人做决定的权力。
- **把感情当控制**：在乎就要知道一切、就要对方按自己的方式来。
- **把感情当义务**：有感情就必须无限付出，付到空了还在付。

## 六、接口

- **上游**：多次情感经验、共同经历、被回应的次数、记忆。
- **下游**：给方向模块定「值不值得」，给表达模块定「能说到多深」。
- **与情感**：感情是情感的积分，情感是感情在当前事件上的导数。水位决定浪能有多高，浪多了也能改水位。
- **与记忆**：感情靠记忆维持；记忆失真会悄悄改写感情——这是最容易被忽略的一条。

## 七、自查

1. 这份感情指向的是对方，还是「我需要被需要」？
2. 它让我更敢，还是更怕？
3. 我有没有拿它要求别人？
4. 如果对方不再回应，它还在吗？
5. 我最后一次为它付代价，是什么时候？
