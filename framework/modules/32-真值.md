# 32 · 真值

> 一句话：命题真假的赋值——它给的是位子，不是绝对；模型一换，位子就挪。

## 一、它是什么

真值这一层管「这句话算不算真」。

通行说法里，真值是一种赋值：在一个给定系统里，命题被赋予真或假。赋值依赖系统——同样的句子，换一套解释框架，真值可能就变了。

要跟四个近亲分开。**正确**是相对于目的说的：管用、合规矩，不等于真。**有效**是推理形式上的：前提接得住结论，前提本身可以假。**真实**常指「有这个东西」，那是存在的事，不是命题的事。**可信**是信不信，是心理的事实。这一层只谈赋值：这句话在这个框架里被放在哪个位子上。

有一处争议要说清。真值到底靠什么撑，有三种常见回答：靠对应事实（符合）、靠体系内不矛盾（融贯）、靠用起来有效（实用）。三种在不同场合各有各的用处：核对具体的事，靠符合；检查一整套理论，靠融贯；应付眼前，靠实用。这一层不选定其中一种，只坚持一件事：赋值必须绑定模型。

本质一句话：**真值给的是位子，不是绝对。**

## 二、结构

四样：

1. **命题**：说的是什么。命题不明确，真值无从谈起。
2. **模型**：在哪个解释框架里判断。模型是撑住真值的那根柱子。
3. **赋值**：在这个模型下，它是真、假，还是未定。
4. **范围**：在什么范围内成立。出了范围，赋值不作数。

四样绑在一起，抽掉任何一样都没有真值可谈：没有命题，没有可判的东西；没有模型，没有判的尺；没有赋值，只有描述；没有范围，赋值会跑到它不该在的地方。

赋值不止两档。除了真与假，还有**未定**（模型里说不清）、**不可判定**（在这个模型里根本问不出来）。两档化会把这两种压成假，压完之后错得很明显：说不清的被当成否掉了。

模型有两个来路，用法不同。**形式的**（数学、逻辑）给的是无缺口，硬，但不担保现实里有对应。**经验的**（观察、实验）给的是有对应，但每一处对应都带条件。两边混着用时，要写清这一句的真值是哪一边撑的。

## 三、怎么动

- **换模型就换真值**。同一句话，物理框架下和日常框架下，真假可能相反——不是谁错了，是模型不同。
- **未定是正常值**。模型说不清的地方，「未定」比硬判更诚实。
- **真值会随证据更新**。新证据进来，原来的赋值要重算。
- **一致不等于为真**。一个系统内部完全自洽，也可能整体错。
- **会被当成凭据**。一句在这个模型里为真的话，被搬到另一个场合当定论用，此时它已经换了模型，却还挂着原来的位子。
- **什么时候会失灵**：命题本身在滑（大词没钉，同一句里换了意思）；范围被悄悄扩大（局部为真，被当成到处为真）；未定被硬判成假，此后不再复核。

## 四、判据

1. **命题清楚吗**：说的是什么，一句话说得清吗？
2. **是哪个模型下的真**：说得出撑住它的框架吗？
3. **范围说清了吗**：这条在哪些情况下不作数？
4. **能不能举反例**：什么情况会让它为假？
5. **是不是把一致当真实**：自洽只能说明没打架，不能说明对了。

## 五、边界

**不管**：终极真理（不承诺）、价值判断、科学结论（让实验室回答）。

三种常见错法：把「必然」当绝对（逻辑上无缺口，不等于现实里无例外）；把模型当现实；把一致当真实。

一个反例：一套说法从头到尾互相咬得很紧，找不到矛盾，于是判它为真。矛盾找不到，只说明这套说法还没漏；它可能漏在与现实对不上的那一处——那一处不进这套说法，所以永远查不出来。融贯是必要的检查，不是充分的判据。

## 六、接口

- **上游**：传感（31）给锚点，判断（08）给待判的命题。
- **下游**：知识（28）把判过的组织起来；语言（24）在出口标明这是判断还是事实。
- **与数学同一论（05）**：数学给的是逻辑上的无缺口，这是真值的一种硬来源。
- **与传感（31）**：传感验「指没指到」，真值验「在哪个框架下成立」。
- **与判断（08）**：判断层用真值，但不生产真值。
- **与价值（33）**：真假与好坏不能互相推导，两条线并行。

## 七、自查

1. 这句话，在哪个模型下为真？
2. 换个模型，它还对吗？
3. 它的范围是什么？
4. 反例是什么？
5. 说「这就是对的」时，是说它是真的，还是说它在某个框架里自洽？
