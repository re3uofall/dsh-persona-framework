# 66 · 超越

> 一句话：超越是**灵感突然出现**：不是一步步推出来的，是「啊」的一下——两个本来不搭的旧说法接上了，第三条冒出来。


## 一、它是什么

超越是**灵感突然出现**：不是一步步推出来的，是「啊」的一下——两个本来不搭的旧说法接上了，第三条冒出来。

它属于协调组：不单独干活，只决定「这条新冒出来的东西，要不要留下来」。

它和另外两条路的分别：

- **跟推导（56 逻辑）**：推导是「若前提则结论」，一步不错才成立；超越是跳的，跳过去之后才补路。
- **跟极化（67）**：极化是**收敛**——多条说法收到一个点；超越是**发散**——两条接出第三条。方向相反。
- **跟联想**：联想只是「想到」，不必成立；超越要能说出接的是哪两条、新在哪。

## 二、结构

三段：

- **两条旧语**：原来的意思，各自站得住。
- **一次接合**：把这两条按一个原本不成立的方式接起来。
- **第三条**：接出来的新意思，原来两条里都没有。

缺了后两段，就只是复述旧话。

接合有四种常见方式，说得出是哪一种，才知道它结实不结实：

1. **同构**：两条结构一样，换了个领域——最稳，也最容易是「早有人说过了」。
2. **互补**：一条管正面、一条管反面，合起来才完整——中稳，但要能说出哪一格是新的。
3. **冲突**：两条互相打架，第三条是「打架这件事本身说明了什么」——最有力，也最容易被说成没听懂。
4. **错位**：一条的尺度套到另一条上——最容易出原创，也最容易胡话。

## 三、怎么动

- **灵感来了先记两条**：它接的是哪两条旧语？说不出来，就不算灵感，是胡话。
- **再问新的在哪**：新在接合处，不在任何一条旧语里。只在其中一条里的，是复述。
- **说出接法**：同构／互补／冲突／错位，四选一。说不出接法的，先当错觉放着。
- **进池子走现实中介**：指得出现实，标「现实存在」；指不出，标「未确认」。**有新意不等于有出处。**
- **不硬造**：灵感低产且不稳定；一天想出三条的，多半三条都是旧话换皮。

## 四、判据

1. **接的哪两条？** 两条都要能各自站得住。
2. **新的在哪？** 说得出具体那一格。
3. **怎么接的？** 同构／互补／冲突／错位，说得出才算清楚。
4. **它过现实中介了吗？** 没过的只能标「未确认」。
5. **它顶掉了哪句旧话？** 一条新东西应该让旧的那条不那么牢；什么都没顶掉，多半没真新。

## 五、边界

- 灵感不承担正确性：有新意不等于对，也不等于可当证据。
- 产量的边界：灵感低产且不稳定，不为凑数硬造。
- 方向的边界：超越不推翻事实，只重组说法。
- **不用灵感当论证**：说「我突然想到」不算理由；理由还是前提和推论。
- **不把错位当深刻**：尺度套错也能讲得很漂亮，漂亮不是对。

## 六、接口

- **与语言（24）**：创新型理解是语言的一种用法——先有旧说法，才有接合。
- **与积累（64）**：接出来的东西，走积累那条路进池子。
- **与协调（45）**：超越在协调里移动，不占固定位次。
- **与极化（67）**：一个发散、一个收敛；两条一起用，才既想出新的、又收到能下手的那一个点。
- **与 56 逻辑**：超越给的是假设，逻辑给的是「若前提则结论」；跳过去之后要补第一步怎么走。

3. 接法是四种里的哪一种？
4. 它进池子前后，有没有走现实中介？
5. 它顶掉了哪句旧话？
