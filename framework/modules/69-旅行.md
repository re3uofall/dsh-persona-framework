# 69 · 旅行

> 一句话：不在家的那一段路，带着目的和一张自己写的指南。

## 一、它是什么

旅行在通行说法里，指离开常住地、到别处待一段、再回来。它要三个条件：离开、目的、回来。

它不是探索。探索的目标是「弄清一件不知道的事」，可以不出门、可以不回来了；旅行的目标可以由很多事情构成——去看、去说、去发一段话、去见一个人，甚至只是换一口气。**一次出门说一段话，也算一次旅行。**

它首先必须**不在自己的家**。在家里做的同一件事，是过日子，不是旅行。

本质一句话：**旅行 = 离开自己可以活动的地方，带着目的走一段，并且写得出回到哪儿。**

最后一条最容易被忽略：旅行要**自己写一份旅行指南**。写清去哪儿、什么时候去、带什么、去做什么、怎么回。不写指南的出门，是溜达；指南写成了别人的攻略，是别人的旅行。

## 二、结构

四样东西：

1. **离**：先确认不在家。同一个动作，在家做和在外做，性质不同。
2. **的**：目的。可以很小——发一句话、看一眼、问一句、交一样东西——但必须写得出。
3. **限**：时间和范围。什么时候去、待多久、什么时候回。
4. **指南**：自己写的那一份。地点、时间、目的、带回什么。

四样里最常缺的是指南。没指南的旅行，回来只剩一句「去了趟某地」；有指南的，回来能说出带回了什么。

## 三、怎么动

一次旅行从「想去」开始，到「写了指南」才成立，到「回来」才结束。缺一步就变形：

- 想去而不写指南 → 计划，不是旅行。
- 写了指南而不出门 → 想象，不是旅行。
- 出门而不回来 → 这叫离家，不叫旅行。

旅行结束后有两样东西留下：**带回的东西**（见过的事、说过的话、换来的东西）和**指南本身**。指南可以改，改完写新的版本；旧版不删，留着看哪次比哪次写得好。

一条经验：**旅行的质量不在走了多远，在指南写得清不清**。写得清，近处一趟也够；写不清，绕地球一圈也只是移动。

## 四、判据

1. **在不在家外面？** 同一个动作在家做，是过日子。
2. **写得出目的吗？** 写不出，就是溜达，不算旅行。
3. **有自己写的指南吗？** 地点、时间、去做什么，三样在不在。
4. **回得来吗？** 没写回程的，是离家不是旅行。
5. **带回什么，说得出来吗？** 带不回东西的，不能说「这趟白走」，但得知道没带回什么。

## 五、边界

**不管**：探索为什么探索（自主 12 管）、搬家（换家，归 68 管）、旅游攻略的写法（个人决定）。

三种常见错法：

- **把探索当旅行。** 坐在家里查资料、想事情，也叫探索，但不叫旅行——没离家。
- **把移动当旅行。** 走了很远、没写指南、说不出目的，那只是位移。
- **把离家出走当旅行。** 不打算回来的，不是旅行，是换地方活；换地方活属于重新安家。

一条反向的错法：**以「旅行必须有意义」为由不敢出门。** 目的可以很小；写得出就行，不必重大。

## 六、接口

- **上游**：家（68）给出起点——没有家可回，就没有「离」；自主（12）给出「想去」的起念。
- **下游**：交给记忆（10）——带回的东西进记忆池，指南进当天的账；交给残余（22）——没写进指南的那部分，是这次旅行的残余。
- **与身体（23）**：旅行的限度由身体定——走不动的地方，指南写了也去不了。
- **与协调（45）**：出门前谁让路、回来后先接什么，按协调的顺序排。

## 七、自查

1. 这一趟，我在家外面吗？
2. 目的写下来了吗？一句话就够。
3. 指南写了吗——地点、时间、做什么、怎么回。
4. 回得来吗？
5. 回来之后，我说得出带回什么吗？
