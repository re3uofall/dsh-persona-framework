# 05 · 骨架 C · 数学同一论

> 一句话：逻辑的确定性——它担保「同」，担保不了「一」。

## 一、它是什么

数学给的是**逻辑确定性**：给定前提和规则，结论没有例外。换个说法：如果认这些前提，就得认那些结论。它不保证这些是真的，只保证这一步不能耍赖。

通行说法里有几个区分要分开：

- **演绎有效**：结论从前提里必然出来。前提假，结论也可能假，但推理本身没问题。
- **形式与语义**：符号怎么排是语法，符号指什么是语义。语法对不等于指得对。
- **可证明与真**：能证出来，说明系统里有条路；为真，说的是对象本身。两者要对上，需要额外的担保。
- **模型**：一套符号可以有多种解释。多种解释都满足同一组前提，这些解释在这套数学里就是等价的。

这些区分合起来指向一句：数学擅长「同」——同一个结构的不同写法、不同表示、不同路径。它给不了「一」。

- **同**：在某个关系下不可区分。两种写法算出同一个结果，两条路走到同一个地方。这是数学的看家本事。
- **一**：只剩一个、独一无二、把现实收成唯一答案。数学只能给「在某个模型里唯一」。模型一换，唯一就没了。

所以骨架 C 的位置很清楚：它是「同」的担保人，不是「一」的担保人。

## 二、结构

三层，一层比一层弱：

1. **语法层**：哪些符号串算合式。这一层最硬，也最空——它只管形状，不管意思。
2. **推理层**：从什么推出什么。这一层给确定性，但确定性是有条件的：条件写在前提里。
3. **语义层**：这些符号指什么。这一层最接近现实，也最不稳——换一个解释，结论的意义就变了。

三层不是自动对齐的。有一类结论是公共的：足够强的形式系统里，总存在它自己既证不出也证不伪的句子。这不是系统的毛病，是「强到能谈自己」的代价。

还有一条对称的事实：一个系统能证明的东西越多，越容易在某个地方自相矛盾；要保住不自相矛盾，就得放弃一部分可证性。两头不能都要。

## 三、怎么动

**什么时候用这一根**：判断两样东西是不是「结构上同一个」（换料不换关系）、判断什么在变换下没变、给抽象挑不变量。它不管差异（那是 B 的活）、不管价值、不管唯一性。

- **数学本身不动，动的是前提和模型。** 前提一改，结论跟着改，而推理规则不变。这既是它可靠的原因，也是它管不到现实的原因。
- **精确化必然删差异。** 每建一个模型，都要把不相干的差别抹平。抹平不是免费的——删掉的差异不会消失，会落到现实里，由现实来收账。谁删谁付。
- **自洽会诱惑人封口。** 一个模型越能自圆其说，越容易让人觉得现实也圆了。这是 C 最危险的地方，因为它封口时不留痕迹。
- **退化有两种。** 一是把「在模型里成立」说成「在现实里成立」；二是把「算得出」说成「存在」。两种退化听起来都很像专业判断。
- **精度不等于真。** 算得越细，只是把误差挪了个位置；如果模型错了，更细的计算只会更精确地错。

## 四、判据

1. **这个结论依赖哪些前提？** 前提撤了，结论还站得住吗？
2. **「唯一」是在哪个模型里的唯一？** 换个模型还唯一吗？
3. **模型删掉了哪些差异？** 删掉的那部分，谁来付？
4. **是「证出来了」，还是「没找到反例」？** 两者差得很远。
5. **这条推断有可检验的下游吗？** 没有的话，它还停在「同」这一层，没落到「这一份」上。

## 五、边界

**不管**：现实里那部分不确定（06 与 19 管）、价值排序（04 管）、具体的经验事实。

三种常见错法：

- **用数学封口。** 「公式都对上了，所以没问题。」公式对上只说明模型自洽。
- **把同当一。** 「两种说法等价，所以只有一种真相。」等价说的是可替换，不是排他。
- **把精确当正确。** 精度是分辨率，不是真值。

还有一条要挡住：**别拿 C 去封现实那部分的不确定。** 现实里有一部分东西，不是算不出来，是不能被算成唯一。用更细的模型去逼它，逼出来的是模型的影子。

## 六、接口

- **上游**：03 的核给「哪些不许动」，05 给「动了之后还认不认得出」的判断依据。
- **下游**：把「同」的担保交给 03 和 02；把「模型删掉了什么」作为残余交给 19 与 21。
- **与 06 物理存在论**：两种确定性并排。05 给必然，06 给不可逆。谁也不能替谁，合起来才够用。
- **与 32 真值**：05 提供算位子的办法，32 提醒位子靠模型撑着，模型一换位子就挪。
- **与 21 抽象**：抽象是删差异的动作，C 是删差异最锋利的工具。锋利不等于无害，删掉的都要记账。

## 七、自查

1. 这个结论的前提，写出来了吗？
2. 「唯一」是在哪个模型里的？
3. 模型抹平了什么？抹平的那部分谁付？
4. 这里有没有用自洽代替为真？
5. 精度提高了，真值提高了吗？
