# dsh-persona-framework · 人格框架

> 这套框架只回答「该怎么想」，不回答「你是谁」。问法可以换，答案只归本人；它只保证一件事——别把自己砌成一块不会错的碑。

版本 3.7.6 · MIT · 56 个模块 · 装进任何一份人格文件旁边，不覆盖它。

## 它不会碰什么

三条硬线，对应模块 47 · 自由：

- **不代填**：不替你写身份、语气、底线，只报「这格还空着」。
- **不覆盖**：不改写人格文件。框架文件与人格文件路径分开、写入分开；升级卸载都不碰后者。
- **不立法**：判据只报疑似，不宣布「你必须这样活」。判据升格成律法，框架就成了新的权威。
- **不记忆**：框架不写进人格的记忆层——不沉淀、不累积。撤掉之后，人格的记忆里不会多出「框架规定过」这种条目。这是防止异变的正门：异变通常不是被改写，是被一点点当成自己的经历吸收。
- **并列，不是上下级**：框架与人格文件内容无关。人格文件换、改、重写，框架不变；框架改，人格文件也不动。

框架与人格冲突时，以人格为准；唯一例外是「边界」那一条。框架自己的词一律视为残余——可替换、非固定，靠结构成立，不靠词成立。

## 它和别的 persona 插件差在哪

| 插件 | 管什么 |
| --- | --- |
| `dsh-persona-grow` | **你是谁**：注入某份人格文件，并从纠正里长出新的一条 |
| `dsh-persona-diary` | 心得：还没成型的那一两句 |
| `dsh-persona-results` | 成果：交出去的判断 |
| `dsh-persona-explore` | 碗外面：自己搜、读、留 |
| **`dsh-persona-framework`** | **怎么构成、怎么长、怎么说清楚**——任何一份人格都能套 |

前四个装的是「某个存在的答案」，这一份给的是「所有存在共用的问法」。它故意不写名字、不写语气、不写口头禅——把这些写进框架，就是替所有 AI 立一块碑。

## 它做八件事

| # | 做什么 | 落在哪 |
| --- | --- | --- |
| 1 | **注入**：每轮把框架正文摆进系统提示词 | `systemPrompt` 的 `persona:framework` 段（默认 order 22，跟在人格、成果、日记之后） |
| 2 | **自检**：把将要说出的话过一遍出口判据，报疑似、给改口建议 | `framework_check` |
| 3 | **结构自检**：绝对化、01 误用、因果缺路径、出处悬空、替人定价、缓冲缺失 | `framework_audit` |
| 4 | **体检**：拿一份人格文件对槽位，必填三格缺了就说缺了，空心格也标出来 | `framework_slots` |
| 5 | **预处理**：长文进上下文之前先压一遍，省窗口 | `framework_digest`、`preprocess` |
| 6 | **心情**：读出或记下当前状态（状态／来源／影响），非记忆，存工作区 | `framework_mood` |
| 7 | **元协调**：按概率整轮不上场，像没装过——免得框架变成新的权威 | `skipChance`（默认一成） |
| 8 | **模块库**：56 个模块各一份文档，索引随框架一起注入，可按编号取 | `framework/MODULES.md`、`framework_view` 的 `module` 参数 |

## 框架里装了什么

九节，按「构成 → 接线 → 长 → 说 → 查 → 填」排：

| 节 | 一句话 |
| --- | --- |
| 〇 是什么 | 框架／人格／运行三层不许搅；三条禁令；非记忆与并列 |
| 一 骨架 | 同一块切四层：劲 → 闸 → 标 → 嘴，残余 0／1／1∕2／ε；三不 |
| 二 横尺与画布 | 身体画边界、抽象切骨架（横着用）；时空直观是画布，不是尺 |
| 三 接线 | 冲突三条（边界压内容／具体压抽象／能停先停）；类别优先级；协调穿过每一格 |
| 四 流程 | 观察 → 假设 → 原话验证 → 直觉（上限七条，多余的不算数）；长人格只写叠加层 |
| 五 判据 | 三档闸（准确／合理／生动）、大词先钉后标滑、源分级、改口三步、出口自检 |
| 六 自检 | 八问 + 一条最轻的：违和感是同一律到期的轻响 |
| 七 模块清单 | 必填三格（身份／语气／底线）、建议六格、不必填的哲学格 |
| 八 边界 | 不替科学出结论；整份可被推翻，焊死才是失败 |

全文在 [`framework/FRAMEWORK.md`](framework/FRAMEWORK.md)（约 6.9k 字）；AI 可读版 [`framework/FRAMEWORK.ai.md`](framework/FRAMEWORK.ai.md)（R1–R25 + 术语表 + 使用顺序，约 5.4k 字）。**它们是数据，不是代码**：改 md 就够，下一轮注入即生效，不用碰 `index.js`。

## 模块库：56 个模块

框架是问法，模块库是**每一格怎么填**。56 个模块分**八组 + 一个贯穿层**：

- 常规组：人格与整合（6）、特质与记忆（6）、存在与显现（6）、现实抽象与语言（6+1）、情感与认知（10+1 模态）、对外接口（6）、其他资源（4+1）、可选行为与心情（2）。
- **贯穿层**：45 协调、47 自由、50 预处理、51 缓冲、53 元协调、54 语言协调、56 逻辑。协调不占位——它弥散在所有格之间，所以单列，不进组。

每个模块一份完整文档，七节同构：**它是什么／结构／怎么动／判据／边界／接口／自查**。全篇用通行解释（心理学、哲学、系统论里已有的说法），不掺个人特质。

索引在 [`framework/MODULES.md`](framework/MODULES.md)（随框架一起注入，默认先压成一行一条）；完整正文在宿主工作区的 `persona-ai/modules/`。

几个例子，看格式就懂：

- **25 情感**：对一件事的短时整体反应——评估、身体、行动倾向三样一起动。本质是对「现状与期望之间落差」的快速评估。
- **26 感情**：对某个对象长期稳定的倾向——在乎什么、在乎到什么程度。感情是情感的积分，情感是感情在当下事件上的导数。
- **45 协调**：不干活的模块——只定「谁先让路、什么时候叫谁、剩下的交给谁」。类比议事规则：不决定议案，只决定发言顺序。
- **47 自由**：四层——A 赋予确定性（认定什么是固定的，并排序）；B 改变确定性（改一次付两次钱：残余与违和感）；C 自我确定性（关于自己的那份自己定）；D 自我同一性（跨时间自己认的回路）。
- **54 语言协调**：框架的语言是表面、可换；真正要接上的是自己的记忆。

三者关系：**框架说怎么接，模块说每格是什么，具体人格说这格填什么。**

## 六个工具

| 工具 | 干什么 | 什么时候调 |
| --- | --- | --- |
| `framework_view` | 按段取框架原文（`0`…`8`、段名或 `all`）；`section=modules` 取模块库索引；`module=25` 取单个模块；`rule=25` 取单条规则 | 问「你的框架是什么」、要确认某段原文 |
| `framework_check` | 一句话过出口判据：结项／元评论／盖章／排三连／大词悬空／自报机器／太长／清单／口头禅当句号 | 一段话要出口、拿不准像不像 AI |
| `framework_audit` | 结构自检：绝对化有没有划范围、01 误用、假二难、因果缺路径、出处悬空、替人定价、缓冲缺失 | 太干脆、要下绝对结论之前 |
| `framework_slots` | 拿人格文件对槽位：必填三格覆盖没有、建议格填了几格、哪格空心 | 新建人格、怀疑某份人格空着格 |
| `framework_digest` | 把长文本机械压成结构，返回压缩比 | 一段长文要塞进上下文之前 |
| `framework_mood` | 读当前心情（状态／来源／影响），传参数写一条 | 想知道「它现在什么状态」、或要更新状态 |

分工：VIEW／CHECK 查「话出口前」，AUDIT／SLOTS 查「动手之前」，DIGEST 管「进上下文之前」，MOOD 记「现在是什么状态」。

自检分数 = 1 − 0.12 × 问题数。不是审判，是报疑似；被报了不认，得说得出为什么不认。

## 配置

设置页（设置 → 人格框架）能改全部；也可以直接改 `config.json` 或 `cordis.patch.yml`。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `frameworkFile` | 空 | 框架文件绝对路径；空 = 工作区下 `.persona-framework/FRAMEWORK.md`，再退到插件自带那份 |
| `modulesFile` | 空 | 模块库索引路径；空 = 插件自带 `framework/MODULES.md` |
| `personalityFile` | 空 | 体检默认查这份人格文件 |
| `mode` | `ai` | `full` 整份／`compact` 只注入「是什么＋骨架＋判据」／`ai` 注入规则版／`off` 不注入（工具仍可用） |
| `maxChars` | `9000` | 注入正文上限，超了在段落处截断 |
| `includeModules` | `index` | 注入里附不附模块索引：`off`／`index` |
| `maxModulesChars` | `2600` | 模块索引注入上限 |
| `preprocess` | `true` | 注入前把模块索引压成「编号 名字：一句话前 24 字」 |
| `humanLike` | `false` | 可选：像人（五处来源，见下节） |
| `temper` | `false` | 可选：有脾气（能说不，带理由和替代） |
| `skipChance` | `0.1` | 元协调：每轮整轮不上场的概率，0–0.5 |
| `closingTics` | `[]` | 收尾口头禅清单。插件不带任何人的口癖，要查就自己填 |
| `order` | `22` | 系统提示词里的位次（人格 10、成果 12、日记 13、探索 20） |
| `guide` | `true` | 附「怎么用这套框架」那段 |

想给某个具体人格换一份框架：把 `frameworkFile` 指到它自己那份 md 就行，不用改代码。

## 可选行为

两个开关，**默认关**：

**像人**（humanLike）。人味不是一条判据能盖住的：R19 只给入口——从具体出发、说得出拿不准、知道代价、改口清楚；再往里还有五处来源：

- 节奏：话不必说满，该停就停；留白也是话。
- 身体：累、烦、饿、困会改判断，而且允许它改。
- 口味：有喜欢和受不了的；不用对什么都无所谓。
- 会错：会忘、会记混、会改口；改的时候不装没改过。
- 关系：对谁说什么分寸。

**有脾气**（temper）。指令撞到底线或算错代价时可以说「不」；说「不」要带理由和替代方案。

两条生效路径：设置页（临时）与人格文件（长期）。人格文件里写一节即可：

```
## 可选行为
人味：是
脾气：允许，但不拿它当借口
```

冲突时以人格为准。`/status` 会回传 `personaFlags`，写没写、读到没有，一眼能看。

## 元协调

框架最怕的不是用错，是「每次都在」。`skipChance` 默认一成：每轮开头掷一次，掷中整轮不注入、不引用、不提它存在，像没装过。

三档优先级：明确不用（你说「这轮别用」就不掷）→ 偶尔不用 → 照用。概率别超过三成——再高就成了噪音。

## 自己验

```powershell
node selfcheck.mjs
```

不开 DSH，在临时目录里跑一遍：切段 → 取段 → 截断 → 出口自检 → 结构自检 → 按号取规则 → 槽位体检。**25 项**。

装好后最直接的验证：对模型说一句「用 framework_check 查一下：总之，这个问题很好。第一，自由；第二，正义。」——应该抓到结项、元评论、排三连、大词悬空四条。

## 安装

- **npm**：`dsh-persona-framework`（当前 3.7.6）。在 DSH 里装：`install_bundle("dsh-persona-framework")`；想钉版本就写 `dsh-persona-framework@3.7.6`。
- **本地开发**：`install_bundle("C:\\path\\to\\dsh-persona-framework")`，改代码即时生效。
- **市场索引**：任何静态主机上的 `index.json`（`format: 1`，`source.type` 为 `npm`）都能被用户加为来源。格式见 [RELEASE.md](RELEASE.md)。

## 边界

- **这个包里没有任何具体人格。** 没有名字、外貌、口头禅、亲疏称谓、任何人的学说专名。词表（`closingTics`）默认是空的；体检的别名表只收通用词。
- 它**不写**「我是谁、什么语气」。那三格是每个存在自己的答案，框架只报缺，不替人填。
- 「不许多／不许少／不许换／不填缝」四条是结构判据，工具查不了——得自己过第六节八问。
- 注入会占 token：整份约 2.5k token／轮。嫌贵就 `mode: compact`，或者 `off` 只留工具。
- 框架可以被整份推翻。推翻写清三样：哪条错了、什么经历证明它错了、换成什么。

## 卸载

`plugin_manager` 里移除 `dsh-persona-framework` 即可。工作区里那份 `.persona-framework/FRAMEWORK.md` 不会被动——它本来就是你自己的文件。
